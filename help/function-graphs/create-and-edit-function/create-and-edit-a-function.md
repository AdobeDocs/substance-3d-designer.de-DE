# Erstellen und Bearbeiten einer Funktion

## Erstellen einer Funktion

Um eine Funktion zu erstellen, müssen Sie nur auf das Funktionssymbol ![](create-and-edit-a-function.resources/image2017-3-7-17-10-8.png) klicken und &quot;**Leere Funktion**&quot; auswählen.

![](create-and-edit-a-function.resources/image2017-3-7-17-8-37.png)

## Bearbeiten einer Funktion

Nachdem eine Funktion erstellt wurde, können Sie sie ändern, indem Sie erneut auf das Funktionssymbol klicken oder in der Dropdown-Liste Bearbeiten auswählen.

![](create-and-edit-a-function.resources/image2017-3-7-17-11-42.png)

Sie geben dann in den Funktionsmodus des Graphen ein.

## Der Funktionsgraph

Das Funktionsdiagramm funktioniert genauso wie andere Diagrammtypen in Designer: mit einem Knoten-Editor.

## Knoten erstellen

Sie können Knoten erstellen, indem Sie mit der rechten Maustaste auf das Diagramm klicken und &quot;Element hinzufügen&quot; auswählen oder indem Sie die Leertaste drücken:

![](create-and-edit-a-function.resources/capture-d-e-cran-2015-02-04-10-05-16.png){width="600px"}

## Festlegen einer Ausgabe

Im Gegensatz zum Substance-Graphen hat die Funktion keinen &quot;Output&quot;-Knoten, Sie müssen angeben, welcher Knoten im Graphen die Funktionsausgabe ist.

Sie können eine Ausgabe festlegen, indem Sie mit der rechten Maustaste auf einen Knoten klicken und <b> &quot;Als Ausgabeknoten festlegen&quot; auswählen.</b>

Der als Ausgabe festgelegte Knoten wird gelb.

>[!NOTE]
>
> **Ausgabetyp**
> 
> Der Knoten, den Sie als Ausgabe festlegen möchten, muss denselben Werttyp wie der von ihm gesteuerte Parameter enthalten. Andernfalls wird die Option &quot;Als Ausgabeknoten festlegen&quot; ausgegraut.

>[!WARNING]
>
> Eine Funktion muss über eine Ausgabe verfügen, damit sie funktioniert. Wenn für Ihre Funktion kein Ausgabesatz vorhanden ist, wird in Ihrem Diagramm eine Warnung angezeigt.
