## Beschreibung

Legen Sie die Grundfarbe des Materials einer SDF-Szene fest.

Diese Farbe kann dann für alle verstreuten SDF-Formen in der *SDF color*-Ausgabe des [Shape-Splatters v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) abgerufen werden.

</td>

</table>

## Eingaben

|                            |                                  |
|----------------------------|----------------------------------|
| <b>SDF-Szene</b> *Fließkommazahl* | Die Eingabe-SDF-Szene. |
| <b>Grundfarbe</b> *Fließkommazahl3* | Der festzulegende Wert für die RGB-Grundfarbe. |
