## Beschreibung

Legen Sie die Material-ID einer SDF-Szene fest.

Dieser Wert kann dann für alle verstreuten SDF-Formen in der *Splatter UVW*-Ausgabe des [Shape-Splatters v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md) abgerufen werden.

## Eingaben

|                          |                        |
|--------------------------|------------------------|
| <b>SDF-Szene</b> *Gleitend* | Die Eingabe-SDF-Szene. |
| <b>ID</b> *Integer* | Die festzulegende Ganzzahlen-ID. |
