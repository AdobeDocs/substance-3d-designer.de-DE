# Version 2019.1 (9.1)

**Substance Designer 2019.1** stellt ein neues Update für das Substance Engine bereit, um seine Funktionen sowie zusätzliche neue Filter weiter zu erweitern.

## Wichtigste Funktionen

### Neuer Wertprozessor Node

![](version-2019-1-9-1.resources/version-2019-1-9-1-01.png)

Das Substance Engine ist jetzt in der 7. Version und bringt damit das neue Konzept der &quot;Werte&quot; in den Compositing-Graf. Werte sind Zahlen und keine Texturen und können daher zur Ausführung verschiedener Berechnungen verwendet werden, die über die Funktions- und Compositing-Grafen knotenübergreifend gemeinsam genutzt werden können. Der Wertprozessor-Knoten kann ein Eingabebild lesen und einen einzigen Ausgabewert berechnen.

Der Wertprozessor ist nicht der einzige Knoten, der Informationen über den Graf übertragen kann. Es wurden einige Änderungen und Ergänzungen vorgenommen:

* Ausgabeknoten können direkt mit einem Wert und nicht mehr notwendigerweise einem Bild gespeist werden.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-02.png)
* Ein neuer **Eingabeknoten** mit dem Namen &quot;Eingabewert&quot; wurde hinzugefügt, damit der Graf Werte abfragen kann.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-03.png)
* Unter den Parametern der Knoten befindet sich jetzt eine neue Kategorie namens &quot;Eingabewerte&quot;, mit der Eingabewerte für den Knoten selbst erstellt werden können.\
  Die Eingangswerte können dann innerhalb des Funktions-Grafen über die &quot;Get&quot;-Knoten referenziert werden.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-04.png)

>[!NOTE]
>
> Wie bei jeder größeren Änderung des Substance Engine wird der Kompatibilitätsmodus auf die vorherige Version eingestellt (neue Version 6 standardmäßig). Inkompatible Knoten haben also einen gelben Rahmen im Graf. Um den gelben Rahmen zu deaktivieren/auszublenden, ändern Sie einfach die Engine-Version in den Haupteinstellungen in die neueste Version (über die Projekteinstellungen) :
> 
> ![](version-2019-1-9-1.resources/version-2019-1-9-1-05.png)

### Unterstützung von Optix in Bakern

![](version-2019-1-9-1.resources/version-2019-1-9-1-06.jpg)

Das letzte Update von Substance Designer hat DXR eingeführt, das es ermöglicht, GPU-Raytracing auf kompatibler RTX-kompatibler Hardware auszuführen. Wir haben jetzt Unterstützung für [Optix](https://developer.nvidia.com/optix) hinzugefügt, die es ermöglicht, auf anderen Nvidia-GPUs auch unter Linux Raytracing durchzuführen. Bei Verwendung von Optix können Sie erwarten, dass der Baking führ mindestens **5 Mal schneller ist** als bei Verwendung von regulärem CPU-Raytracing.

Hier ist die Liste der Baker, die von dieser Änderung betroffen sind:

* Ambient occlusion vom Mesh
* Gebeugte Normale aus Mesh
* Thickness aus Gitter

Wenn Sie eines der beiden Backends deaktivieren möchten, navigieren Sie zu den Hauptvoreinstellungen (**Bearbeiten > Voreinstellungen**) und zu den Einstellungen für Bäcker :

![](version-2019-1-9-1.resources/version-2019-1-9-1-07.png)

>[!NOTE]
>
> Stellen Sie für den Zugriff auf die Funktion sicher, dass Sie **auf die folgenden Treiber aktualisieren**:
> 
> * Nvidia 10XX und 20XX GPUs : **Treiber 430.39** (kompatibel mit DXR und Optix)
> * Nvidia 9XX und älter : **d** **Treiber 419.67 oder 430.39** (Treiber 425.31 haben ein Problem mit Optix)
> 
> Beachten Sie, dass DXR auch für [GeForce GTX 10xx GPUs](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/) (mit aktuellen Treibern) verfügbar ist. Für DXR muss Windows ebenfalls auf dem neuesten Stand sein, um zu arbeiten. Weitere Informationen finden Sie unter [dieser Seite](../../../best-practices/performance-optimization/performance-optimization-guidelines.md).

### Verbesserte Ladezeiten für OBJ-Gitter

![](version-2019-1-9-1.resources/version-2019-1-9-1-08.jpg)

In dieser Version haben wir unseren **obj**-Dateileser verbessert, um die Ladezeit von 3D-Meshes zu reduzieren. Die Ladezeiten wurden bis zu dreimal beschleunigt, insbesondere für Meshes, für die keine UVs und Normale definiert sind.

Diese Leistungsverbesserung wirkt sich sowohl auf den Bäcker als auch auf die 3D-Ansicht aus.

### Verbessertes Python-Plugin-System

![](version-2019-1-9-1.resources/version-2019-1-9-1-09.png)

Mit diesem Update haben wir dem Scripting-System eine Menge neuer Funktionen hinzugefügt:

* **Unterstützung von Qt** : Ermöglicht das Erstellen einer benutzerdefinierten Benutzeroberfläche, die dem Stil der restlichen Anwendung entspricht. Benutzerdefinierte Benutzeroberfläche kann mit diesem neuen System auch viel einfacher integriert werden. (Tkinter ist jetzt veraltet.)
* **Rückruffunktionen** : Es ist nun möglich, Rückruffunktionen zu registrieren. Derzeit umfasst es nur das Öffnen und Speichern von Dateien sowie das Erstellen von UI-Elementen. Weitere Rückrufe werden in Zukunft hinzugefügt.
* **Threading** : Plug-ins können jetzt Threads erstellen, um Hintergrundverarbeitung durchzuführen oder auf Betriebssystemereignisse (wie Netzwerkverbindungen) zu warten.

Weitere Informationen finden Sie im Änderungsprotokoll der API, auf das über den Menüeintrag **Hilfe > Python-API-Dokumentation** im Substance Designer zugegriffen werden kann.

### Neue Inhalte

In der Standardbibliothek sind auch einige neue Knoten verfügbar, von denen einige jetzt mit dem neuen Knoten des Value-Prozessors ausgestattet sind:

* **Flood Fill in Index**\
  Weist Formen aus einem Flood Fill einen eindeutigen Index zu.\
  Im folgenden Beispiel entspricht der Knoten &quot;Pixelprozessor&quot; der Form &quot;Value Input&quot; (Werteingabe) und gibt als Ergebnis eine Maske aus.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-10.gif)
* **Non Uniform Directional Warp**\
  Wendet eine Richtungsverzerrung an, bei der die Intensität und der Winkel von den Bildeingaben aufgenommen werden.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-11.gif)
* **Mehrere Richtungsverzerrungen**\
  Verkrümmt das Eingabebild mehrmals in verschiedene Richtungen.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-12.gif)
* **Höhenextrusion**\
  Generiert ein orthografisches 3D-Rendering des angegebenen Heights. Die Kamera kann mit dem Positions-Gizmo gesteuert werden.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-13.gif)
* **Min./Max. Wert**\
  Gibt den minimalen und maximalen Pixelwert aus dem Eingabebild zurück.

  ![](version-2019-1-9-1.resources/version-2019-1-9-1-14.png)

>[!WARNING]
>
> Diese Version unterstützt CentOS 6.x nicht mehr. Um die neueste Version von Substance Designer zu verwenden, führen Sie ein Upgrade auf CentOS 7.x durch.
