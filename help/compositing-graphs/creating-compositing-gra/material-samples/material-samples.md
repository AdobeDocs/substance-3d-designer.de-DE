# Material-Samples

![Materialproben - Vorlagenkarten](material-samples.resources/materialSamples-cards.png "Materialproben - Vorlagenkarten")

Designer bietet eine kuratierte Auswahl an Beispielgrafiken aus verschiedenen Materialtypen, aus denen Sie lernen und mit denen Sie experimentieren können.

Die Beispiele sollen als Diagrammvorlage verwendet werden, d. h., <b> kann auf diese zugreifen, indem ein neues Substance-Diagramm erstellt wird</b>.
Das neue Diagramm ist eine <b>vollständig bearbeitbare Kopie</b> des Beispiels, die Sie bearbeiten, auseinander nehmen und erweitern können, wie Sie möchten.
Aus den Beispielen kannst du beliebig viele neue Diagramme erstellen.

Alle Beispiele basieren auf dem **OpenPBR**-Materialmodell, einem neuen Industriestandard mit wachsender Unterstützung.

Beim Erstellen eines neuen Substance-Diagramms finden Sie die Beispiele im [Dialogfeld &quot;Neues Substance-Diagramm&quot;](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md):

Doppelklicken Sie auf ein beliebiges Element, um aus diesem Beispiel ein neues Diagramm zu erstellen. Sie können auch das Beispiel auswählen und auf
die Schaltfläche <b>Erstellen</b>.

Doppelklicken Sie auf ein beliebiges Element, um aus diesem Beispiel ein neues Diagramm zu erstellen. Sie können auch das Beispiel auswählen und auf
die Schaltfläche <b>Erstellen</b>. Sobald eine Materialprobe ausgewählt und die Diagrammerstellung validiert wurde, wird das Dialogfeld geschlossen.
und eine Kopie des Beispiels wird als neues Diagramm in der Diagrammansicht geladen.

Standardmäßig wird die erste Ausgabe der Probe in die 2D-Ansicht geladen und die Texturen werden auf die 3D-Ansicht angewendet.
Ihr Arbeitsbereich wird automatisch eingerichtet und Sie können loslegen. (Dies kann in den [Voreinstellungen](../../../interface/preferences-window/preferences-window.md) von Designer geändert werden.)
