# HSL

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![Elementare Knoten: HSL](hsl.resources/comp_hsl_1.png "Elementare Knoten: HSL"){width="100%"}

</td>
<td style="border: 0;" valign="top">

Passt den Farbton, die Sättigung und die Helligkeit eines Farbbildes an.

Es handelt sich um einen einfachen, benutzerfreundlichen Knoten, der bei der Arbeit mit Farbdaten sehr nützlich ist.

Wenn Sie nach anderen Möglichkeiten suchen, die Farbtöne eines Bildes zu bearbeiten, sehen Sie sich [Kurve](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/curve/curve.md), [Tonwertkorrektur](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md) und [Kontrast/Luminanz](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/contrast-luminosity/contrast-luminosity.md) an.

</td>
</tr>
</table>

## Parameter

|  |  |
| --- | --- |
| <b>Farbton</b> *Fließkommazahl* | Legt die Farbe des Eingabebilds fest.   Werte unter 0,5 verschieben den Farbton negativ, Werte über 0,5 verschieben ihn positiv. |
| <b>Sättigung</b> *Fließkommazahl* | Bestimmt die Sättigung der Farbpalette des Eingabebilds.   Werte unter 0,5 verringern die Sättigung, Werte über 0,5 erhöhen sie. |
| <b>Helligkeit</b> *Fließkommazahl* | Bestimmt die Helligkeit des Eingabebilds Werte unter 0,5 verringern die Helligkeit, Werte über 0,5 erhöhen sie. |

## Eingabe-Verbindungen

|  |  |
| --- | --- |
| <b>Eingabe</b> *Farbe* PRIMÄR | Bild, das verarbeitet werden soll. |
