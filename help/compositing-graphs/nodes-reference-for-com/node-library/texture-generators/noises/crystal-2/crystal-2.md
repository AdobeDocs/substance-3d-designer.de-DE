## Beschreibung

Erzeugt ein angular-Faltenmuster. Ähnlich wie [Crease Rauschen](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/creased/creased.md).

Das ist eine Nische-Rauschen: Das kann in seltenen Fällen nützlich sein, wenn Sie nach dieser Art von Details suchen, z. B. wenn Sie subtile Marmormuster nachstellen oder Tuch machen.

</td>
</tr>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Skalierung</b> <i>1 - 16</i> | Legt die globale Skalierung für den Effekt fest. |
| <b>Störung</b> <i>0.0 - 1.0</i> | Phasenverschiebt das Rauschen, um kleine Schwankungen einzuführen. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
