## Beschreibung

Dieser Knoten erzeugt ein einfaches Webmuster mit einigen Optionen. Es ermöglicht mehr Kontrolle als die vordefinierten Webmuster und stellt ein Muster dar, das mit anderen Knoten nicht erreicht werden kann.

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Kachel X</b> <i>1 - 20</i> | Legt fest, wie viele Blöcke auf der X-Achse wiederholt werden. |
| <b>Kachel Y</b> <i>1 - 20</i> | Legen Sie fest, wie viele Blöcke auf der Y-Achse wiederholt werden sollen. |
| <b>Form</b> <i>0.0 - 1.0</i> | Legt das Kurvenprofil des Heights fest. |
| <b>Web</b> <i>1 - 10</i> | Legt fest, wie viele Maschen pro Block verwendet werden. |
| <b>Lücke</b> <i>0.0 - 1.0</i> | Legt den Abstand zwischen den Maschen auf der X- und Y-Achse fest. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
