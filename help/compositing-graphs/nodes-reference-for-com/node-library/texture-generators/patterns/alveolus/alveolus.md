<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Kacheln</b> <i>1 - 16</i> | Legt fest, wie oft das Ergebnis gekachelt werden soll. |
| <b>Mit Verlauf gefüllte Zellen</b> <i>False/True</i> | Schaltet auf scharfe Kanten um, wodurch scharfe Sechseckfliesen entstehen. |
| <b>Schnittstellenbreite</b> <i>0.0 - 1.0</i> | Funktioniert nur, wenn die obige Option auf &quot;Falsch&quot; gesetzt ist. Ändert die Schnittstellengröße. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
