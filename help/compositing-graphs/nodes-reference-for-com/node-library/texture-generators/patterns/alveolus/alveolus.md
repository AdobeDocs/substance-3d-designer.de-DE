## Beschreibung

Ein Soft-Sphere-Muster, das alternativ Hexagon-Kacheln erzeugen kann.

## Parameter

* **Anordnen**: *1 - 16*\
  Legt fest, wie oft das Ergebnis gekachelt werden soll.
* **Zellen mit Farbverlauf ausgefüllt**: *Falsch/Wahr* Wechselt zu scharfen Kanten und erstellt scharfkantige Sechseckkacheln.
* **Schnittstellenbreite**: *0.0 - 1.0* Funktioniert nur, wenn die obige Option auf &quot;False&quot; festgelegt ist. Ändert die Schnittstellengröße.
* **Quadratische Ausbreitung**: *False/True*\
  Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen.
