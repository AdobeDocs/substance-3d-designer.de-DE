## Beschreibung

Sehr einfaches Prüfmuster. Die Kachelung wird bewusst niedrig angesetzt, um sie so allgemein wie möglich zu machen.

Es ist aufgrund seines auffälligen Kontrasts und seiner Kachelung ein nützliches Testfallmuster.

</td>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Kacheln</b> <i>1 - 16</i> | Legt fest, wie oft das Ergebnis gekachelt werden soll. |
| <b>Um 45 Grad drehen</b> <i>False/True</i> | Dreht das gesamte Muster um 45 Grad. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
