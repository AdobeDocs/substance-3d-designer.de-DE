## Beschreibung

Generiert eine Polygonform mit vielen Anpassungsoptionen. Eine einfachere Version finden Sie unter [Polygon 2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-2/polygon-2.md).

## Parameter

* **Seiten**: *3 - 32* Legt die Anzahl der Seiten fest, die das Polygon haben soll.
* **Explodieren**: *0.0 - 1.0* Verschiebt Polygon-&quot;Slices&quot; auseinander.
* **Dreiecksgröße**: *0.0 - 1.0* Passt die Größe von Slices/Dreiecken an. Durch jede Anpassung könnte die Form auseinandergebrochen werden - nur bei 1,1. ist perfekt vernetzt!
* **Skalierung**: *0.0 - 1.0* Skaliert die gesamte Form als eine.
* **Automatische Skalierung**: *Falsch/Wahr* Passt die Skalierung so an, dass das gesamte Polygon mit Standardparametern in die Ansicht passt.
* **Drehung**: *0.0 - 1.0* Dreht die gesamte Form.
* **Verlauf**: *Falsch/Wahr* Generiert Verlaufsscheiben/Dreiecke anstelle von Volltonrastern. Hinweis: ähnelt Polygon 2, wenn diese Einstellung aktiviert ist.
* **Verlaufsumkehr**: *Falsch/Wahr* Spiegelt die Verlaufsrichtung, wenn &quot;Verlauf&quot; aktiviert ist.
* **Anordnen**: *1 - 16*\
  Legt fest, wie oft das Ergebnis gekachelt werden soll.
* **Quadratische Ausbreitung**: *False/True*\
  Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen.
* **Kachelung (nicht quadratisch)****:** *Falsch/Wahr*Wenn die Quadratische Ausbreitung aktiviert ist, wird die Form ohne Unterdrücken kachelbar.
