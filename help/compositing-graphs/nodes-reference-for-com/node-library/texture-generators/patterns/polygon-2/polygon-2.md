## Beschreibung

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Seiten</b> <i>3 - 32</i> | Anzahl der Seiten. |
| <b>Skalierung</b> <i>0.0 - 1.0</i> | Legt die globale Skalierung fest. |
| <b>Drehung</b> <i>0.0 - 1.0</i> | Dreht die gesamte Form. |
| <b>Kurve</b> <i>-1.0 - 1.0</i> | Ändert die Verlaufsprofilkurve. |
| <b>Verlauf</b> <i>0.0 - 1.0</i> | Passt den Verlaufskontrast an. |
| <b>Verlauf umkehren</b> <i>False/True</i> | Kehrt die Verlaufsrichtung um. |
| <b>Automatische Skalierung</b> <i>False/True</i> | Skaliert so, dass es in die Arbeitsfläche mit Standardeinstellungen passt. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
