## Beschreibung

Dies ist ein hilfreicher Knoten für das Generieren prozeduraler Panoramakarten vom Typ &quot;Studio&quot;. Ermöglicht es Ihnen, Spotlight-Bilder zu platzieren und zu ändern sowie ihre HDR festzulegen. Es kann für mehrere Formen verkettet werden.

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Formmatrix</b> | Verschiebt oder Kamera bewegt das Ergebnis, kann durch direkte Interaktion mit der Arbeitsfläche geändert werden. |
| <b>Form</b> <i>Quadrat, Datenträger</i> | Legt den Formtyp fest. |
| <b>Formfarbe</b> <i>(Farbwert)</i> | Legt die Formfarbe fest. |
| <b>Formintensität</b> <i>0.0 - 100.0</i> | Legt HDR Intensität der Form fest. |
| <b>Weicher Rand der Form</b> <i>0.0 - 1.0</i> | Ändert die Weichheit der Begrenzungslinien der Form. |
| <b>Hotspot-Intensität</b> <i>0.0 - 100.0</i> | Legt HDR Intensität des Hotspots fest. |
| <b>Hotspot-Größe</b> <i>0.0 - 1.0</i> | Ändert die Größe des Hotspots innerhalb der Form. |
| <b>Hotspot-Falloff</b> <i>0.0 - 1.0</i> | Ändert den Abfall und die Kantenüberblendung des Hotspots. |
| <b>Hotspot-Position</b> <i>0.0 - 1.0</i> | Verschiebt den Hotspot in Bezug auf die Form. |
| <b>Hintergrund aktivieren</b> <i>False/True</i> | Ermöglicht das Füllen des Hintergrunds mit einer Volltonfarbe. Beachten Sie, dass Sie sie nicht mehr durch Mischen miteinander verknüpfen können. |
| <b>Hintergrundfarbe</b> <i>(Farbwert)</i> | Legt die Farbfläche des Hintergrunds fest. |
| <b>Textur-Eingabe aktivieren</b> <i>False/True</i> | Ermöglicht eine benutzerdefinierte Eingabe anstelle eines vordefinierten Formtyps. |
