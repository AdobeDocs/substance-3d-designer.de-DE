<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Orientierungsversatz</b> | Ermöglicht eine 3D-ähnliche X- und Y-Drehung des Würfels. Dies kann auch durch Bearbeiten des kleinen Punkts in der 2D-Vorschau erfolgen. |
| <b>Größe</b> <i>0.0 - 1.0</i> | Ermöglicht eine ungleichmäßige Skalierung des Würfels. |
| <b>Skalierung</b> <i>0.0 - 1.0</i> | Skaliert den gesamten Würfel gleichmäßig. |
| <b>Quadratische Ausbreitung</b> <i>False/True</i> | Ermöglicht die Kompensation von Quetsch und Dehnung bei nicht quadratischen Verhältnissen. |
