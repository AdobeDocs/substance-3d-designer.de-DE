# Texturgeneratoren

Texturgeneratoren sind Knoten, die keine Eingaben benötigen: Sie generieren Bilder komplett von Grund auf neu. Sie können sich &quot;Texturgeneratoren&quot; als ein anderes Wort für &quot;Prozedurale&quot; vorstellen.

Sie sind in zwei Kategorien unterteilt:

* [Störungen](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  Rauschen sind die echten prozeduralen Grafiken, zufälligen Formen und Pixel, wie bekannte Perlin- und Cloud-Rauschen.
* [Muster](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  Muster sind meist künstliche Formen, die wie von Menschen geschaffen aussehen. Sie können aber auch mit vielen zusätzlichen Steuerelementen randomisiert werden.
