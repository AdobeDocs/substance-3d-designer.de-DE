# Effekte (Material)

Diese Kategorie enthält Material, die vollwertige Knoteneffekte generieren, ähnlich der Funktionsweise von [Verwitterung](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/weathering/weathering.md)-Knoten. Der Hauptunterschied besteht jedoch darin, dass diese Effektknoten jedes beliebige Material als Eingabe verwenden können. Sie benötigen auch eine durch Baking erzeugte Map als Eingabe, meist eine Heightmap.

Zwei gute Beispiele sind [Wasserstand](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/water-level/water-level.md) und [Snow-Abdeckung](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/snow-cover/snow-cover.md).
