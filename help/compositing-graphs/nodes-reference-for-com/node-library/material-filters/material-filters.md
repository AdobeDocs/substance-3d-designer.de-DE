# Materialfilter

Materialfilter sind Knoten, die mit Eingaben für Vollmaterial arbeiten: Kombinationen aus mehreren Kanälen, die am besten über [Link Creation Modes](../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) verwendet werden. Jedes Mal, wenn Sie mit einem vollständigen PBR-Material arbeiten und nicht nur mit einem einzelnen Kanal wie &quot;Grundfarbe&quot; oder &quot;Normal&quot; oder einer einfachen Schwarz-Weiß-Maske, sollten Sie die Kategorie &quot;Materialfilter&quot; verwenden.

Diese Kategorie umfasst eine Reihe von Unterkategorien:

* [1-Klick](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/1-click/1-click.md)\
  Enthält nur Bitmap2Material.
* [Effekte](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/effects-material.md)\
  Originelle All-in-One-Effekte.
* [Transformationen](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/transforms-material/transforms-material.md)\
  Multikanal-Transformationshilfe.
* [Überblenden](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/blending-material.md)\
  Mehrkanal-Überblendknoten.
* [PBR-Dienstprogramme](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-utilities.md)\
  PBR-Hilfsknoten und -Tools.
* [Scan-Verarbeitung](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md)\
  Werkzeuge speziell für fotogescannte Texturen.
