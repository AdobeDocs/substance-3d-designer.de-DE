# Materialfilter

Materialfilter sind Knoten, die mit Eingaben im vollständigen Material funktionieren: Kombinationen aus mehreren Kanälen, die am besten über [Link Creation Modes](../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md) verwendet werden. Jedes Mal, wenn Sie mit einem vollständigen PBR-Material arbeiten und nicht nur mit einer Ein Kanal wie &quot;Grundfarbe&quot; oder &quot;Normal&quot; oder einer einfachen Schwarzweiß-weiße Maske, sollten Sie die Kategorie &quot;Materialfilter&quot; verwenden.

Diese Kategorie umfasst eine Reihe von Unterkategorien:

* [1-Click](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/1-click/1-click.md)\
  Enthält nur Bitmap2Material.
* [Effekte](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/effects-material.md)\
  Material-Effekte.
* [Transformieren](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/transforms-material/transforms-material.md)\
  Helfer zur Transformation auf mehreren Kanälen.
* [Überblenden](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/blending-material.md)\
  Mehrkanal-Überblendknoten.
* [PBR-Dienstprogramme](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-utilities.md)\
  PBR Helfer Nodes und Tools.
* [Scanverarbeitung](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md)\
  Speziell für fotogescannte Texturen vorgesehene Werkzeuge.
