# Mesh-basierte Generatoren

Mesh-basierte Generatoren sind Knoten, die [Durch Baking erzeugte Map](../../../../bakers/bakers.md) verarbeiten sollen, z. B. Normalen-Map, Krümmung, Ambient occlusion usw.

Ihren Namen bekommt diese Kategorie dadurch, dass durch Baking erzeugte Map die einzige Möglichkeit für Designer darstellen, Daten aus 3D-Meshs zu verwenden. Einige Funktionen in dieser Kategorie sind mit [Intelligente Materialien und Masken](https://experienceleague.adobe.com/de/docs/substance-3d-painter/using/features/smart-materials-and-masks) von Substance 3D Painter vergleichbar.

Es gibt drei Hauptkategorien:

* [Maskengenerator](mask-generators/mask-generators.md)\
  Schwarz-weiße Maske-Generatoren auf der Basis von einem oder mehreren durch Baking erzeugte Map.
* [Verwitterung](weathering/weathering.md)
Effekte auf Basis von durch Baking erzeugte Map für Verwitterung im gesamten Material.
* [Dienstprogramme](utilities-mesh-based-gen/utilities-mesh-based-generators.md)\
  Zusätzliche Utilitys und Tools für die Arbeit mit Baking führte.
