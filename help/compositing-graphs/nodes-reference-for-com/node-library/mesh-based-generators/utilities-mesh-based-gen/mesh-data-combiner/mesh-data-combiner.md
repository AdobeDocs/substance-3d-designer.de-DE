## Beschreibung

Es handelt sich um einen sehr einfachen Knoten, der &quot;gebackene&quot; Gitterdaten in einer einzigen Gruppe &quot;zusammenfasst&quot;, um sie mit &quot;Kompakter Materialmodus&quot; zu verwenden.

Dieser Knoten ist meistens ein Helfer, der es einfacher macht, mit vielen gebackenen Eingaben auf bestimmten Knoten in der Galerie zu arbeiten, wie [Material Mesh Data Blender](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/utilities-mesh-based-gen/material-mesh-data-ble/material-mesh-data-blender.md). So können Sie vermeiden, alles manuell zu verbinden.

## Parameter

### Parameter

Schaltet um, welche Zuordnungseingaben aktiviert und in das gepackte Ergebnis ausgegeben werden sollen.

* **Ambient-Verdeckung**: *False/True*
* **UV-Masken**: *False/True*
* **Krümmung**: *False/True*
* **Height**: *False/True*
* **Position (Graustufen)**: *False/True*
* **Thickness**: *False/True*
* **Normal**: *False/True*
* **Position (RGB)**: *False/True*
* **Farb-ID**: *False/True*
* **Weltraumrichtung**: *False/True*
* **Normaler Weltraum**: *False/True*
