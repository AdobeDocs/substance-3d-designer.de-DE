## Beschreibung

Dies ist ein sehr einfacher Mesh, der Baking geführt Knotendaten in einer einzigen Gruppe &quot;zusammenfasst&quot;, um sie mit &quot;Compact Materialmodi&quot; zu verwenden.

Dieser Helfer ist meist ein Knoten, der die Arbeit mit vielen Baking geführt Eingaben auf bestimmten Knoten in der Galerie erleichtert, z. B. [Material Mesh Data Blender](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/utilities-mesh-based-gen/material-mesh-data-ble/material-mesh-data-blender.md). So können Sie vermeiden, alles manuell zu verbinden.
