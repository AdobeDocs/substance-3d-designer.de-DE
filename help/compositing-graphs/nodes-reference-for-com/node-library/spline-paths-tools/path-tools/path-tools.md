# Pfadwerkzeuge

Pfadwerkzeuge sind eine Sammlung von Knoten zum Generieren und Anpassen von Pfaden sowie zum Konvertieren in Splines, um Bilder komplexer zu streuen oder zu verformen.

Pfade bestehen aus einer Reihe von Punkten, die in gerade Linien verbunden sind.

Sehen Sie sich dieses Tutorial an, um gleich loszulegen:

>[!TIP]
>
> Es wird empfohlen, [mit Pfad und Spline-Werkzeugen](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/working-with-path-and-spl/working-with-path-and-spline-tools.md) zu arbeiten, um die Toolset optimal zu nutzen.
> 
> Für fortgeschrittene Benutzer wird in der [Paths Format Specification](../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/paths-format-spe/paths-format-specifications.md) erläutert, wie die Daten von Pfaden in Farbbildern codiert werden, und es werden Tipps zum direkten Bearbeiten dieser Daten bereitgestellt.
