# Pfade-Polygon

<td width="33.33%" style="border: 0;" valign="top">

</td>
<td width="100.00%" style="border: 0;" valign="top">

## Beschreibung

Generiert ein primitives (Polygon) im Pfadformat.

Verwenden Sie den Knoten [Pfad 2D transformieren](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/path-2d-transform/path-2d-transform.md), um die Grundform präzise zu positionieren.

</td>
</tr>
</table>

<a name="outputs"></a>

## Ausgaben

|  |  |
|:---|:---|
| <b>Pfade</b> <i>Farbe</i> | Enthält eine Liste mit einem codierten Pfad und einer Liste mit codierten Segmenten.<br>Dies ist nicht für die direkte Verwendung oder Änderung vorgesehen. Suchen Sie nach Pfaden, um kompatible Knoten zu finden. |

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Anzahl der Seiten</b> <i>Integer</i> | Tipp: Geben Sie einen Wert zwischen 100 und 1000 ein, um einen Kreis zu erstellen. |
