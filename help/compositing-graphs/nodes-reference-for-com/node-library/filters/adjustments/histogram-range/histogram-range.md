## Beschreibung

Verringern und/oder Verschieben des Bereichs einer Graustufeneingabe. Kann verwendet werden, um Überblendungen neu zuzuordnen, ähnlich wie [Kontrast Luminanz](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/contrast-luminosity/contrast-luminosity.md), aber mit verschiedenen Steuerelementen, die für einige Situationen sinnvoller sein können.\
Weitere, nützlichere Möglichkeiten zum Neuzuordnen des Bereichs finden Sie unter [Histogrammscan](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md).

[Klicken Sie hier, um ein Substance Academy-Video über Histogramme anzuschauen.](https://www.youtube.com/watch?v=p9wcmJBFyGA&t=517s)

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Bereich</b> <i>0.0 - 1.0</i> | Gibt an, wie stark der Bereich von unten nach unten reduziert werden soll. Dies ähnelt dem Verschieben der Schieberegler &quot;Tonwertspreizung&quot; und &quot;Max&quot; nach innen. |
| <b>Position</b> <i>0.0 - 1.0</i> | Versatz für die Bereichsreduzierung, Festlegen eines anderen Mittelpunkts für die Bereichsreduzierung. |
