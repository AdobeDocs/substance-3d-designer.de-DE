## Beschreibung

Der Farbton verschiebt die Quellfarbe in Richtung der Zielfarbe.

Weitere erweiterte Versionen finden Sie unter [Farbbereich ersetzen](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/replace-color-range/replace-color-range.md) oder [Farbabgleich](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/color-match/color-match.md).

## Parameter

* **Quellfarbe**: *(Farbwert)*Farbe, von der aus der Farbton verschoben wird.
* **Zielfarbe**: *(Farbwert)*Farbe, in die der Farbton verschoben werden soll.
