<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Bereichsmin.</b> <i>-2.0 - 0.0</i> | Minimaler Bereich für den Beginn der Markierung. |
| <b>Max. Bereich</b> <i>1.0 - 3.0</i> | Maximaler Bereich, bis zu dem hervorgehoben werden soll. |
