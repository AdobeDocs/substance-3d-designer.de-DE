## Beschreibung

Erweiterter Knoten zur schnellen Graustufen-Konvertierung, der einige voreingestellte Konvertierungsmodi bietet.

</td>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Graustufen-Typ</b> <i>Sättigung, Luminanz, Durchschnitt, Max, Min.</i> | &quot;Sättigung verringern&quot; setzt den Sättigungswert auf 0, &quot;Luminanz&quot; verwendet die offiziellen Kanalgewichte, &quot;Durchschnitt&quot; ist identisch mit dem Wert des elementaren Knotens und &quot;Max&quot; bzw. &quot;Min&quot; verwenden den hellsten Wert für jeden Luminanz. |
