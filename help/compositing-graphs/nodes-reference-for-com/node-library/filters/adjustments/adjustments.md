# Korrekturen

Dies ist eine der Hauptfilterkategorien, mit Knoten, die dazu bestimmt sind, die Werte und Bereiche der Eingaben auf verschiedene Weise anzupassen. Bei den meisten Nodes handelt es sich um eine erweiterte und erweiterte Möglichkeit zur Verwendung von [Levels](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)- und [Überblendung](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blend/blend.md)-Nodes. Sie sind als intelligentere Verknüpfungen zu bestimmten Vorgängen gedacht.

Verwenden Sie die <b>Navigationsliste auf der linken Seite</b>, um alle Knoten unter &quot;Korrekturen&quot; zu durchsuchen.
