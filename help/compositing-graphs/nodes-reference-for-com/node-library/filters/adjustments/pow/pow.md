## Beschreibung

Führt die Eingabe mit einem angegebenen Exponenten aus. Ähnlich wie das Anpassen der [Ebenen](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)Mittelpunkt, jedoch in einem einfacheren Paket. Dies ist auch nützlich, wenn Sie eine exakte mathematische Energieoperation ausführen möchten.

Wichtig: Achten Sie darauf, die richtige Version zu verwenden, je nachdem, ob Sie eine Farb- oder Graustufeneingabe haben!
