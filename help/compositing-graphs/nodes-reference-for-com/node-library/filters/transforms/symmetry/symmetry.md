## Beschreibung

Führt verschiedene Symmetrien an einem Eingabebild durch. Kann verwendet werden, um geometrische Formen symmetrisch zu machen.

Dieser Knoten ist [Mirror](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/mirror-filter-node/mirror-filter-node.md) sehr ähnlich, verfügt jedoch über zusätzliche Steuerelemente für Mischmodi.

</td>
</tr>
</table>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Symmetrie-Modus</b> <i>Mirror Y, Mirror X, Diagonal Left, Diagonal Right, Mirror X/Y, Mirror X/Mirror Y, Diagonal Left/Diagonal Right, Diagonal Right/Diagonal Left, 8</i> | Wählt den geometrischen Modus der Symmetrie. |
| <b>Übertragungsmodus</b> <i>0 - 6</i> | Wählt die Füllmethode für die Symmetrie: Kopieren, Hinzufügen, Subtrahieren, Multiplizieren, Sub hinzufügen, Max, Min. |
