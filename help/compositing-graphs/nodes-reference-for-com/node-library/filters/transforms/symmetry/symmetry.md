## Beschreibung

Führt eine Vielzahl von Symmetrie-Vorgängen für ein Eingabebild durch. Kann verwendet werden, um geometrische Formen symmetrisch zu machen.

Dieser Knoten ist [Mirror](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/mirror-filter-node/mirror-filter-node.md) sehr ähnlich, verfügt jedoch über zusätzliche Steuerelemente für Mischmodi.

## Parameter

* **Symmetriemodus**: *Mirror Y, Mirror X, Diagonal Left, Diagonal Right, Mirror X/Y, Mirror X/Mirror Y, Diagonal Left/Diagonal Right, Diagonal Right/Diagonal Left, 8* Wählt den geometrischen Symmetriemodus.
* **Übertragungsmodus**: *0 - 6* Wählt Symmetrie-Füllmethode: Kopieren, Hinzufügen, Subtrahieren, Multiplizieren, Sub hinzufügen, Max, Min.
