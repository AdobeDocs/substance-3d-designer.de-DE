## Beschreibung

Spezieller transformieren-Knoten, der die Eingabe in einer Perspektive-/Trapezverzerrungsart ändert. Hat die Steuerung für &quot;Oben&quot; und &quot;Unten&quot; gedehnt. Werte können über Grenzen hinaus verschoben werden, um stärkere Effekte zu erzielen.

</td>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Top Dehn</b> <i>0.0 - 1.0</i> | Lege die Stärke des dehn- oder Squashs oben fest. |
| <b>Unten Gedehnt</b> <i>0.0 - 1.0</i> | Stellen Sie die dehn- oder Squash-Menge an der Schaltfläche ein. |
| <b>Hintergrundfarbe</b> <i>(Graustufen-/Farbwert)</i> | Legen Sie eine einfarbige Hintergrundfarbe fest, falls die Kachelung deaktiviert ist. |
| <b>Sampling</b> <i>Bilinear, nächstgelegen</i> | Legen Sie die Samplingqualität fest. |
