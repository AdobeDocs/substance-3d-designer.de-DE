## Beschreibung

Der Knoten **3D Texture Offset** wendet eine *Offset-Transformation* in den Achsen **X**, **Y** und **Z** auf ein Objekt an, das durch die *3D Textur* beschrieben wird, die mit dem **Eingang** verbunden ist.

</td>
</tr>
</table>

## Parameter

### Eingaben

* **Eingabe** *Graustufen/Farbe*\
  Die *3D-Textur*, die ein 3D-Objekt beschreibt.\
  Das Objekt wird häufig in einem *Einheitscube* beschrieben.

### Parameter

* **Offset** *Float3*\
  Die Menge des Offsets im *Welt-Raum*, der auf das Objekt angewendet wird, das durch die *3D-Textur* beschrieben wird, die mit dem **Eingang** verbunden ist.
