## Beschreibung

Spezieller Transformationsknoten, der die Transformation einer Quad-Form durch Interaktion mit ihren Eckpunkten ermöglicht. Ermöglicht sehr spezifische Transformationen in einer praktischen Weise.

## Parameter

* **p00**: Punkt oben links.
* **p01**: Punkt unten links
* **p10**: Oberer rechter Punkt.
* **p11**: Unten rechts.
* **Ausrechnen**: *Nur Vorderseite, Nur Rückseite, Vorn über Rückseite, Zurück über Vorderseite* Legen Sie das Keulen/Ausblenden der Form fest, wenn sich Punkte überkreuzen.
* **Titel aktivieren**: *False/True*
* **Hintergrundfarbe**: *(Graustufenwert)*einfarbiger Hintergrund, wenn die Unterteilung deaktiviert ist.
* **Sampling**: *Bilinear, nächstgelegen* Sampling-Qualität einstellen.
