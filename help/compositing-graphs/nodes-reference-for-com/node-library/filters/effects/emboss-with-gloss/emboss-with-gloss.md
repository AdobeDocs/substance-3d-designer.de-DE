## Beschreibung

Führt einen Prägeeffekt mit hinzugefügtem Glanz (Specular-Reflexion) auf eine Farb- und Height-Eingabe durch. Fügt einem Height gefälschte, bakierte Lichter hinzu, die auf Bildinformationen basieren. Nützlich für einige Texturierungs-Stile, bei denen die Beleuchtung bereits in den Texturen enthalten ist.

Eine Version mit weiteren Optionen finden Sie unter [Uber Emboss](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/uber-emboss/uber-emboss.md). Es gibt auch die einfachere, atomare Version von [Relief](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/emboss/emboss.md).

## Parameter

### Eingaben

* **Farbe**: *Farbeingabe*
* **Height**: *Graustufen-Eingabe*

### Parameter

* **Markierungsfarbe**: *(Farbwert)*Farbe der Specular-Markierung.
* **Schattenfarbe**: *(Farbwert)*Farbe, die in schattierten/unbeleuchteten Bereichen verwendet wird.
* **Glanz**: *0.0 - 0.5* Glanzlichtergröße.
* **Intensität**: *0.0 - 10.0* Intensität der Markierung.
* **Lichtwinkel**: *0.0 - 1.0*\
  Einfallswinkel des (gefälschten) Lichts.
