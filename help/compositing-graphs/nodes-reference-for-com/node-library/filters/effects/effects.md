# Effekte

Diese Kategorie enthält eine Vielzahl von Knoten, die für mehrere Verwendungszwecke vorgesehen sind. Diese Nodes sind hauptsächlich für einen Ein Kanal-Eingang bestimmt und führen einen ziemlich fortgeschrittenen Effekt oder eine etwas komplexere Modifikation als Ausgabe durch.

Verwenden Sie die <b>Navigationsliste auf der linken Seite</b>, um alle Knoten unter &quot;Effekte&quot; zu durchsuchen.

Eine große Knotengruppe ist für die Verarbeitung, Generierung und Modifizierung von Durch Baking erzeugte Map, wie Normalmap oder AO und Krümmung, vorgesehen. Beispiele:

* [Krümmung glätten](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/curvature-smooth/curvature-smooth.md)
* [Ambient occlusion (HBAO)](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/ambient-occlusion-hbao/ambient-occlusion-hbao-filter-node.md)

Eine weitere Gruppe von Knoten ist für den Effekt &quot;Ebenenform&quot; oder &quot;Ebenenstile&quot; vorgesehen, wie in anderen gängigen Bildbearbeitungsprogrammen zu sehen ist. Beispiele:

* [Glühen](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/glow/glow.md)
* [Formenkontur](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/shape-stroke/shape-stroke.md)
* [Uber-Relief](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/uber-emboss/uber-emboss.md)

Schließlich gibt es einige nützliche erweiterte Effekte, von denen [Flood Fill](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/flood-fill/flood-fill.md), [Kantenerkennung](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/edge-detect/edge-detect.md) und [Vektorverkrümmung](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/vector-warp/vector-warp.md) die besten Beispiele sind.
