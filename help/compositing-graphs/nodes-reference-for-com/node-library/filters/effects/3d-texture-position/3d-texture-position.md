## Beschreibung

Der Knoten **3D Textur Position** generiert die *Positions-Slices* eines Einheitenwürfels.

Dies kann verwendet werden, um 3D-Rauschen Baking führen oder als *3D-Textur-Atlas* zu fungieren.
