## Beschreibung

Generiert eine sich drehende Bewegungsunschärfe auf einer Eingabe.

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Beispiele</b> <i>1 - 128</i> | Legen Sie die Qualität des Unschärfe-Effekts fest. |
| <b>Winkel</b> <i>0.0 - 0.5</i> | Legen Sie die Stärke des &quot;Spins&quot; des Effekts fest. |
| <b>Mittenposition</b> | Legen Sie den Mittelpunkt des Effekts fest. |
