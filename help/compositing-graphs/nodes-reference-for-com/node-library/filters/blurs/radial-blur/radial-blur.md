## Beschreibung

Generiert eine sich drehende Bewegungsunschärfe auf einer Eingabe.

## Parameter

* **Beispiele**: *1 - 128* Legen Sie die Qualität des Weichzeichnungseffekts fest.
* **Winkel**: *0.0 - 0.5* Legen Sie die Stärke des &quot;Spins&quot; des Effekts fest.
* **Mittenposition**:\
  Legen Sie den Mittelpunkt des Effekts fest.
