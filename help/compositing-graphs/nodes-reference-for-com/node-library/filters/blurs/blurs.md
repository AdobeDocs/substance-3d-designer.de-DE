# Weichzeichnen

Die Kategorie &quot;Weichzeichnen&quot; wird auf [, dem atomaren Knoten &quot;Feld weichzeichnen&quot;, erweitert.](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md) Es enthält erweiterte, qualitativ hochwertigere Weichzeichner, die mehrere Verwendungsmöglichkeiten haben.

Beachten Sie, dass jeder Knoten der Bibliotheksweichzeichnung in einer Graustufen- und Farbversion vorliegt. Versuchen Sie, die Version zu verwenden, die für Ihre Eingabe geeignet ist!
