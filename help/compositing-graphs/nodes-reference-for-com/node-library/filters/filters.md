# Filter

Filter sind Knoten, die einen Input verarbeiten, um eine modifizierte, &quot;gefilterte&quot; Ausgabe zu erstellen, auf eine Weise, die Sie von anderen bekannten Bildbearbeitungsanwendungen gewohnt sein könnten. Der große Unterschied zu [Materialfiltern](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md) besteht darin, dass sie nur an einer (manchmal mehr) Eingabe arbeiten, die kein vollständiges Material darstellt.

Filter sind eine der am häufigsten verwendeten Hauptkategorien. Außer der Kategorie [Elementare Knoten](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md) ist keine andere Kategorie so hilfreich, wenn Sie Texturen von Grund auf neu erstellen. Nehmen Sie sich die Zeit, um jede der Unterkategorien kennenzulernen:

* [Anpassungen](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/adjustments.md)\
  Erweiterte Farb-, Tonwert- und Wertkorrekturen.
* [Überblenden](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blending/blending.md)\
  Erweiterte und erweiterte Füllmethoden.
* [Unschärfen](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blurs.md)\
  Professionelle, hochwertige Weichzeichner.
* [Kanäle](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/channels.md)\
  Erweiterte Kanalmischknoten.
* [Effekte](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/effects.md)\
  Texturierungsorientierte Bildeffekte sowie Effekte vom Typ &quot;Ebenenstil&quot;.
* [Normale Karte](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-map.md)\
  Normalen-Map-spezifische Operationen.
* [Kacheln](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/tiling.md)\
  Nodes mit Schwerpunkt auf der Korrektur und Verbesserung der Kachelung.
* [Transformieren](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/transforms.md)\
  Erweiterte (mathematische) 2D-Raum-Transformationsvorgänge.
