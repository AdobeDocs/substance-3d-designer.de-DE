# Kacheln

Die Kachelkategorie enthält Knoten, die zur Verbesserung der Kachelung von Texturen verwendet werden. Beachten Sie, dass in [Scanverarbeitung](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/scan-processing.md) weitere Knoten dafür verfügbar sind.

Verwenden Sie die Navigationsliste auf der linken Seite, um alle Knoten unter <b>Kacheln</b> zu durchsuchen.

Es gibt zwei Knoten in dieser Kategorie:

* [Kachelüberlagerung erstellen](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-patch/make-it-tile-patch.md)
* [Foto unterteilen.](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/make-it-tile-photo/make-it-tile-photo.md)
