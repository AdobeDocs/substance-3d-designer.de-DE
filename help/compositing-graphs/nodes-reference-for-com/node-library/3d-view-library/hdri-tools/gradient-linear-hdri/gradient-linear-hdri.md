## Beschreibung

Erstellt einen linearen Farbverlauf über die Mitte und mit einem vom Benutzer platzierten Punkt. Das Endergebnis wird für die sphärische Projektion angepasst, im Gegensatz zu dem regulären [linearen Verlauf 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-linear-1/gradient-linear-1.md).

## Parameter

* **Punktposition**:\
  Position des Punktes, der zur Bestimmung der Verlaufsrichtung verwendet wird.
* **Obere Farbe**: *(Farbwert)*\
  Farbe des oberen Teils des Verlaufs (an Punkt)
* **Untere Farbe**: *(Farbwert)*\
  Farbe des unteren Teils des Verlaufs (vom Punkt weg).
* **Kontrast**: *0.0 - 1.0*\
  Passt den Kontrast des Ergebnisses an.
