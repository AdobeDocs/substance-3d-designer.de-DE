## Beschreibung

Erstellt einen linearen Farbverlauf über die Mitte und mit einem vom Benutzer platzierten Punkt. Das Endergebnis wird für die sphärische Projektion angepasst, im Gegensatz zu dem regulären [linearen Verlauf 1](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/gradient-linear-1/gradient-linear-1.md).

</td>

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Punktposition</b> | Position des Punktes, der zur Bestimmung der Verlaufsrichtung verwendet wird. |
| <b>Obere Farbe</b> <i>(Farbwert)</i> | Farbe des oberen Teils des Verlaufs (an Punkt) |
| <b>Untere Farbe</b> <i>(Farbwert)</i> | Farbe des unteren Teils des Verlaufs (vom Punkt weg). |
| <b>Kontrast</b> <i>0.0 - 1.0</i> | Passt den Kontrast des Ergebnisses an. |
