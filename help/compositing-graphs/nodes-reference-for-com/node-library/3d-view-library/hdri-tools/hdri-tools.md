# HDRI-Tools

HDRI-Werkzeug sind Knoten, die für die Bearbeitung und Erstellung von HDR-Bildern vorgesehen sind. Dies bedeutet insbesondere, dass diese Nodes über Funktionen zum Arbeiten und Generieren korrekter High Dynamic Range-Werte sowie Nodes verfügen, die die sphärische Projektion-Zuordnung berücksichtigen und kompensieren.
