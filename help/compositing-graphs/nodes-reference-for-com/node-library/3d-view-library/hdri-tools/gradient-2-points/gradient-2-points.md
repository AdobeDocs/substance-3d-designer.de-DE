## Beschreibung

Erstellt einen Farbverlauf von 2 Farben zwischen zwei vom Benutzer ausgewählten Punkten. Das Ergebnis wurde an die sphärische Projektion angepasst. Ähnlich wie [Gradient Linear (HDRI)](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/gradient-linear-hdri/gradient-linear-hdri.md), jedoch mit zwei anstatt mit einem Punkt.

## Parameter

* **Punkt 1 Position**:\
  Vom Benutzer ausgewählte erste Punktposition. Hat Handle in 2D-Ansicht.
* **Farbe für Punkt 1**: *(Farbwert)*\
  Farbe am Beginn des Verlaufs.
* **Kontrast für Punkt 1**: *0.0 - 1.0*\
  Kontrast der ersten Punktmaske.
* **Punkt 2 Position**:\
  Vom Benutzer ausgewählte zweite Punktposition. Hat Handle in 2D-Ansicht.
* **Farbe für Punkt 2**: *(Farbwert)*\
  Farbe am Ende des Verlaufs.
* **Kontrast für Punkt 2**: *0.0 - 1.0* Kontrast der zweiten Punktmaske.
