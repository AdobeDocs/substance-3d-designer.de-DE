## Beschreibung

Erstellt einen Farbverlauf von 2 Farben zwischen zwei vom Benutzer ausgewählten Punkten. Das Ergebnis wurde an die sphärische Projektion angepasst. Ähnlich wie [Gradient Linear (HDRI)](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/gradient-linear-hdri/gradient-linear-hdri.md), jedoch mit zwei anstatt mit einem Punkt.

<a name="parameters"></a>

## Parameter

|  |  |
|:---|:---|
| <b>Punkt 1 Position</b> | Vom Benutzer ausgewählte erste Punktposition. Hat in der 2D-Ansicht Einfluss. |
| <b>Farbe für Punkt 1</b> <i>(Farbwert)</i> | Farbe am Beginn des Verlaufs. |
| <b>Kontrast für Punkt 1</b> <i>0.0 - 1.0</i> | Kontrast der ersten Punktmaske. |
| <b>Punkt 2 Position</b> | Vom Benutzer ausgewählte zweite Punktposition. Hat in der 2D-Ansicht Einfluss. |
| <b>Farbe für Punkt 2</b> <i>(Farbwert)</i> | Farbe am Ende des Verlaufs. |
| <b>Kontrast für Punkt 2</b> <i>0.0 - 1.0</i> | Kontrast der zweiten Punktmaske. |
