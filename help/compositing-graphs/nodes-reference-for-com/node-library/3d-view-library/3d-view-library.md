# 3D-Ansicht (Bibliothek)

Die Kategorie &quot;3D-Ansicht&quot; enthält nur Knoten, die sich auf sphärische, projizierte HDRIs beziehen. Diese Knoten werden entweder in der 3D-Ansicht von Substance 3D Designer verwendet oder für den Export in andere Anwendungen wie Substance 3D Painter verwendet.

Es gibt zwei Unterkategorien:

* **HDRI-Umgebungen**: Es ist keine Dokumentation verfügbar, da es sich um reine Bilder handelt, die in der 3D-Ansicht ohne zusätzliche Parameter angezeigt werden sollen.
* **HDRI-Werkzeugs**: Tool-Knoten zum Erstellen und Bearbeiten von kugelförmigen HDRI-Bildern. Eingeführt in SD 2019.2.
