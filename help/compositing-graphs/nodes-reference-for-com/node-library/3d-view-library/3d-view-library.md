# 3D-Ansicht (Library)

Die Kategorie &quot;3D-Ansicht&quot; enthält nur Nodes, die sich auf sphärische projizierte HDRIs beziehen, die entweder in der 3D-Ansicht von Substance 3D Designer oder für den Export in andere Anwendungen wie Substance 3D Painter verwendet werden.

Es gibt zwei Unterkategorien:

* **HDRI-Umgebungen**: Es liegen keine Unterlagen vor, da es sich um reine Abbildungen handelt, die für die Anzeige in der 3D-Ansicht vorgesehen sind, ohne dass zusätzliche Parameter angegeben werden müssen.
* **HDRI-Werkzeugs**: Tool-Knoten zum Erstellen und Bearbeiten von kugelförmigen HDRI-Bildern. Eingeführt in SD 2019.2.
