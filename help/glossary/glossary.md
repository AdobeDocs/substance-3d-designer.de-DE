# Erfahren Sie mehr über die in Designer verwendeten Begriffe und Konzepte.

## #&#x200B;

|  |  |
| --- | --- |
| {: #three-d-scene}**3D-Szene** | Eine Sammlung von Objekten und Daten, die bei der Darstellung und Animation einer Visualisierung des 3D-Raums eine Rolle spielen:<ul data-preserve-html="true"> <li data-preserve-html="true">[Mesh](#mesh)</li> <li data-preserve-html="true">[Materials](#material)</li> <li data-preserve-html="true">Kameras</li> <li data-preserve-html="true">Lichter</li> <li data-preserve-html="true">Animation</li> <li data-preserve-html="true">Simulationen</li> <li data-preserve-html="true">...</li> </ul>[Beliebte Dateiformate](https://www.adobe.com/de/products/substance3d/discover/3d-files-formats.html) zum Speichern von 3D-Szenen sind Pixars [USD](#usd) und Autodesk-FBX. Alle Dateiformate unterstützen nicht alle diese Komponenten |

## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #alpha}**Alpha-Kanal** | Der vierte Kanal eines Farbbildes, der häufig zur Beschreibung der Deckkraft verwendet wird. |
| {: #ambient-occlusion}**Ambient occlusion** | Die Dämpfung des Umgebungslichts auf weniger gelegt und daher schwerer zu erreichenden Flächen. |
| {: #anisotropy}**Anisotropie** | Die Eigenschaft, richtungsabhängig zu sein. Mit anderen Worten, die Bereitstellung eines anderen Ergebnisses, wenn es auf einer anderen Achse gemessen oder beobachtet wird.<br><br>Anisotrope Material haben je nach Herkunft ein anderes Aussehen, und anisotrope Filter werden nicht in alle Richtungen einheitlich angewendet. |
| {: #aov}**AOV** | &quot;Arbitrary Output Variable&quot; (AOV) ist ein Begriff, der in [Rendering](#rendering) verwendet wird, um zusätzliche Datenkanäle zu beschreiben, die von einem Rendering ausgegeben werden können, z. B. Tiefe, Normale oder benutzerdefinierte Daten. |
| {: #api}**API** | Eine API (Application Programming Interface) ist eine Sammlung von Funktionen und Prozeduren, mit denen Benutzer auf die Funktionen und Prozeduren einer anderen Anwendung des Programms zugreifen können.<br><br>Eine API stellt eine kontrollierte und sichere Ebene zwischen dem Benutzer und einem Programm bereit. Es kann auch eine andere Programmiersprache verwenden, um die Interaktion mit diesem Programm zu vereinfachen und die Zugänglichkeit zu erweitern.<br><br>Designer bietet eine [Python-API](../scripting/scripting.md), die einfachen Zugriff auf eine Vielzahl von Funktionen bietet, mit denen Daten bearbeitet, benutzerdefinierte Tools erstellt und Workflows beschleunigt werden können. |
| {: #atomic-node}**Elementare Knoten** | Die Grundbausteine von Grafen. Alle [Instanzknoten](#instance-node) können in Graf von elementaren Knoten aufgeteilt werden.<br>Jeder Graf-Typ verfügt über eine eigene Gruppe von elementaren Knoten. |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #baking}**Baking** | Der Vorgang zum Berechnen von Informationen aus einem 3D-Modell und zum Speichern der Ergebnisse in einer [Textur](#texture). Die Daten werden in der Textur gemäß den [UVs](#uv) des Modells platziert. |
| {: #base-color}**Grundfarbe** (Albedo) | Ein Kanal eines [Materials](#material), der mithilfe des Modells der PBR-Metallische Rauheit [Schattierung](#shader) definiert wurde.<br>Grundfarbe gibt die Farbe einer Fläche ohne Beleuchtungsinformationen an.<br><br>Es sollte nicht mit [Diffusen](#diffuse) verwechselt werden. |
| {: #base-parameter}**Basisparameter** | Ein Parameter, der allen Graf in einem Substance-Knoten gemeinsam ist, die eine [Bitmap](#bitmap) berechnen.<br><br>Dazu gehören Kernaspekte der Bitmap, wie z. B. die Auflösung ([Ausgabegröße](#output-size)) und die [Bittiefe](#bit-depth) ([Ausgabeformat](#output-format)), oder wie die Bitmap berechnet wird, z. B. der Modus [Kachelung](#tiling).<br><br>Basisparameter werden häufig [von anderen Knoten im Upstream geerbt](#inheritance) oder von dem Graf, der den Knoten hostet. |
| {: #bilinear-filtering}**Bilineare Filterungen** | Ein Interpolationsvorgang, der im Computerbild verwendet wird, wenn ein [Pixelmuster &#x200B;](#texture-sampling) nicht genau in der Textur eines Pixels ausgeführt wird.<br><br>Dies kann beispielsweise auftreten, wenn ein Bild vergrößert wird. |
| {: #bit-depth}**Bittiefe** | Die Anzahl der Bits, die zum Speichern des Werts eines Pixels in einer Textur verwendet werden. Bei höheren Bittiefen können mehr Werte codiert werden, was zu glatteren Farbverläufen führt.<br><br>Je nach Werttyp stehen verschiedene Bittiefen zur Verfügung: - Werte der Ganzzahl können mit 8 Bit (0 bis 255) oder 16 Bit (0 bis 65 535) codiert werden. - Fließkommawert können mit 16 Bit (+32767.999 bis -32768.0) oder 32 Bit (-3.4E+38 bis +3.4E+38) codiert werden<br><br>Bilder mit niedrigem Dynamikbereich verwenden Ganzzahlen-Werte, um die Schritte von 0 bis 1 zu codieren. High Dynamic Range-Images verwenden Fließkommawerte zur Codierung von numerischen Rohwerten.<br><br>In Substance-Grafen wird die Bittiefe durch den Parameter [Ausgabeformat](#output-format) gesteuert. |
| {: #bitmap}**Bitmap** | Ein digitales Bild. Zwei Arten von Bildern kommen am häufigsten vor:<ul data-preserve-html="true"> <li data-preserve-html="true">Graustufenbild haben nur einen Kanal: Luminanz L;</li> <li data-preserve-html="true">Farbbilder haben drei Kanäle: Rot, Grün und Blau (RGB). Ein vierter kann vorhanden sein: [alpha](#alpha) (A), das häufig für die Deckkraft verwendet wird. Farbbilder in Designer sind immer RGBA.</li> </ul>  Bitmaps können als Raster von Werten aufgefasst werden. Jede Zelle dieses Rasters ist ein Pixel, das für &quot;Bildelement&quot; kurz ist. Ein Pixel speichert einen Wert pro Kanal. Der Typ dieses Werts hängt von der [Bittiefe](#bit-depth) der Bitmap ab. |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #cache}**Cache** (Arbeitsspeicher) | Eine Datenerfassung - z. [Basisparameter](#base-parameter) und Ausgabebilder des Knotens - im Speicher gespeichert, um wiederverwendet zu werden.<br><br>Der Graf beschleunigt die Berechnung erheblich, da das [Substance Engine](#substance-engine) nur die Teile eines Grafen neu berechnen kann, die sich geändert haben. Beim Anpassen von Knotenverbindungen und -parametern sind alle Knotenpunkte, die diesem Knoten vorausgehen, von diesen Änderungen nicht betroffen. Daher müssen sie nicht erneut [ausgewertet](#evaluation) werden, um den Graf zu aktualisieren. Stattdessen wird ihr Cache verwendet.<br><br>Der Cache kann bei der Arbeit mit hohen Auflösungen und Bittiefen in großen Grafen einen erheblichen Speicherplatz beanspruchen. |
| {: #channel-packing}**Kanal-Packing** | Eine Optimierungstechnik, bei der separate Bilder in die RGB(A)-Kanäle eines einzelnen Farbbildes gepackt werden.<br><br>Eine RMA-Textur ist beispielsweise eine [Rauheit](#roughness)-Map (R), eine Metalitätsmap (M) und eine [ambient occlusion](#ambient-occlusion)-Map (A), die alle in einer einzigen farbigen Textur zusammengefasst sind.<br><br>Eine weitere gängige Methode ist das Packing einer Graustufen-Textur in den Blaukanal einer [Normalen-Map](#normal-map), da der Blaukanal - d. h. die &quot;Up&quot;-Komponente des Normalvektors - zur Laufzeit neu berechnet werden kann.<br><br>Der Knoten [RGBA merge](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md) ist nützlich für die Implementierung dieser Technik. |
| {: #color-space}**Farbraum** | Eine Definition der Darstellung eines Farbbereichs.<br>Das digitale Codieren und Decodieren einer bestimmten Farbe erfordert eine solche Definition, um die verwendeten Zahlen zu verstehen.<br><br>Eine Bilddatei speichert Farbwerte mit einem angegebenen Farbraum, sodass diese Farben auf einem Bildschirm, der diesen Farbraum unterstützt, originalgetreu wiedergegeben werden können. Ein Display verfügt über spezielle Farbwiedergabefunktionen, die es ihm ermöglichen, einen bestimmten Farbraum ganz oder teilweise zu unterstützen.<br><br>Rohdaten - z. B. eine [Normalen-Map](#normal-map) - wird immer in einem linearen Farbraum codiert und decodiert, da diese Farben nicht visualisiert werden sollen und keine Transformationen auf diese Daten angewendet werden sollen.<br><br>sRGB ist ein weithin unterstützter Farbraum. Weitere beliebte Farbräume sind Adobe RGB, Rec. 2100 und ProPhoto RGB. |
| {: #cooking}**Kochen** ({: #compilation}Kompilierung) | Der Prozess der Übersetzung von Daten in eine andere Sprache, damit sie schnell und effizient ausgeführt werden können.<br>Das Ergebnis eines Substance-Grafen muss zuerst kompiliert werden. Die Kompilierung ist Teil des [Evaluierungs](#evaluation)-Diagrammprozesses.<br><br>Diese Kompilierung wird auf einem abgeflachten Graf ausgeführt, was bedeutet, dass alle [Instanzknoten](#instance-node) durch ihre Quell-Graf &quot;ersetzt&quot; werden, sodass ein größerer Graf verbleibt und dieser Graf kompiliert wird.<br><br>Ein kompilierter Graf kann nicht bearbeitet werden. Verfügbare Parameter bleiben verfügbar, wenn sie [dynamisch](#dynamic-parameter) sind, während [statische](#static-parameter) Parameter gesperrt und ausgeblendet sind. |
| {: #culling}**Ausrechnen** | Eine Optimierungstechnik zum [Rendern](#rendering) [3D-Szenen](#three-d-scene), die Geometrie aus den Berechnungen eines Renderings entfernt, wenn sie nicht sichtbar ist.<br><br>Dies kann Objekte oder Polygone außerhalb des Frustbestands der Kamera (*Frustum-Keulung*), gegenüber der Kamera (*Rückseiten-Ausblendung*) oder vollständig verborgen durch andere undurchsichtige Objekte (*Verdeckung-Keulung*) einschließen. |

## D

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #dependency}**Abhängigkeit** | Eine Datei A, die von einer anderen Datei B so verwendet wird, dass Datei B nicht wie vorgesehen funktioniert, wenn Datei A fehlt.<br><br>Eine Abhängigkeit eines [Pakets](#package) kann ein anderes Paket sein, da darin auf einen Graf, eine Bilddatei, eine Schriftart usw. verwiesen wird.<br><br>Ein Paket speichert den Pfad zu seiner Abhängigkeit. Wenn die Abhängigkeit an diesem Pfad nicht gefunden werden kann, wird eine Warnung ausgegeben. Fehlende Abhängigkeiten können auch zu [Geisterinstanzknoten](#ghost-instance-node) in einem Diagramm führen. |
| {: #diffuse}**Diffus** | Ein Kanal eines [Materials](#material), der mithilfe des PBR-Specular-Glanzes [Schattierung](#shader) definiert wurde. Diffuse gibt die Farbe einer Oberfläche an, wenn sie beleuchtet wird.<br><br>Es sollte nicht mit [Grundfarbe (Albedo)](#base-color) verwechselt werden. |
| {: #directx}**DirectX** | Eine Sammlung von APIs zur Verarbeitung von Multimedia-Inhalten. Die 3D-API Direct3D ist in der Videospielentwicklung und anderen 3D-Branchen weit verbreitet.<br><br>Direct3D platziert den Ursprung einer Textur - d. h. die Koordinate (0, 0) - in der *oberen linken Ecke* (Y-unten), während die [OpenGL](#opengl)-API sie in der *unteren linken Ecke* (Y-oben) platziert.<br><br>Dies bedeutet, dass eine DirectX [Normalen-Map](#normal-map) einen *invertierten grünen Kanal hat* im Vergleich zu GL. Tatsächlich beherbergt der grüne Kanal die Y-Koordinaten der normalen Vektoren. |
| {: #displacement}**Versatz** | Der Vorgang des Verschiebens der [Scheitelpunkte](#vertex) eines 3D-Modells, häufig entlang der [Normalen](#normal).<br><br>Versatz wird häufig in Verbindung mit [Tessellation](#tessellation) und [Normalen-Map](#normal-map) verwendet, um feinere Details auf einer Oberfläche zu modellieren. |
| {: #dynamic-parameter}**Dynamischer Parameter** | Ein Parameter, dessen Wert sich ändern kann. Mit anderen Worten, jeder Parameter, dessen Wert nicht konstant ist, ist dynamisch.<br><br><br>Dies umfasst freigelegte Parameter, alle Parameter, die von einem freigelegte Parameter betroffen sind, sowie alle Parameterwerte, die von [Sampling in einer Textur betroffen sind](#texture-sampling).<br><br>Im Gegensatz zu [statischen Parametern](#static-parameter) kann der Wert dynamischer Parameter während der Bearbeitung angepasst werden, nachdem der Graf in eine [Sbsar-Datei](#sbsar-file) kompiliert wurde. |

## E

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #evaluation}**Auswertung** | Der Prozess der Auflösung der Weitergabe von Daten und Parametern im Diagramm. Die Auswertung überprüft die Gültigkeit eines Diagramms und seiner Verbindungen, wendet [Vererbung](#inheritance) an und [kocht](#cooking) das Diagramm.<br><br>In der Graphansicht wird eine Verbindung mit einer gepunkteten Linie dargestellt, wenn sie nicht ausgewertet wird.<br>Die Auswertung wandelt die Verbindung in durchgehende Linien um.<br><br><br>Jedes Mal, wenn ein Parameter in einem Graf angepasst wird, sind der Knoten, der diesen Parameter und alle untergeordneten Knoten hostet, [ungültig](#invalidation) und müssen erneut ausgewertet werden, bevor [gerendert](#rendering) wird. |

## G

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #ghost-instance-node}**Ghost-Instanzknoten** | Ein [Instanzknoten](#instance-node), der auf einen [Untergraph](#subgraph) verweist, der nicht gefunden werden kann - d. h. eine fehlende [Abhängigkeit](#dependency) - wird als Phantom-Instanzknoten geladen.<br><br>Phantom-Instanzknoten werden in den erwarteten Zustand zurückgesetzt, indem die fehlende Abhängigkeit aufgelöst und das [Paket](#package) erneut geladen wird. |
| {: #glossiness}**Glossarität** | Ein Kanal eines [Materials](#material), der mithilfe des PBR-Specular-Glanzes [Schattierung](#shader) definiert wurde. Der Glanzgrad gibt die Unschärfe einer Fläche an, d. h. mikroskopische Variationen des Heights, auch als *Mikrofacetten* bezeichnet.<br><br>Hoher Glanz führt zu einem weichen Aussehen, während niedriger Glanz zu einem groben, matten Aussehen führt.<br><br>Dies ist die Umkehrung von [Rauheit](#roughness). |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #histogram}**Histogramm (Bild)** | Im Kontext eines Bildes stellt ein Histogramm die Population der Werte in einem bestimmten Bereich dar - häufig [0, 1].<br><br>Diese Population wird mithilfe von vertikalen Balken visualisiert, wobei ein im Bild stärker vorhandener Wert zu einem höheren Balken für diesen Wert führt.<br>Die Balken werden horizontal von niedrigen (dunklen) zu hohen (hellen) Werten verteilt.<br><br>Histogramme von Farbbildern überlappen in der Regel die Histogramme der einzelnen Kanäle - in der Regel R, G, B. |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #inheritance}**Vererbung** | Im Kontext von Substance-Graphen beschreibt Vererbung die Eigenschaft von Nodes, die Parameterwerte von ihren Upstream-Nodes oder ihrem übergeordneten Graphen erfassen.<br><br>Geerbte Parameter beinhalten [Auflösung](#resolution) ([Ausgabegröße](#output-size)), [Bittiefe](#bit-depth) ([Ausgabeformat](#output-format)) und den Modus [Kachelung](#tiling).<br><br>Weitere Informationen zur Vererbung finden Sie auf dieser [dedizierten Seite](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md). |
| {: #instance-node}**Instanzknoten** | Ein Instanzknoten stellt ein Diagramm A in ein anderes Diagramm B dar. In diesem Fall kann Diagramm A als [Untergraph](#subgraph) von Diagramm B bezeichnet werden. Jede Änderung in Diagramm A wird an alle Instanzknoten weitergegeben, die es darstellen.<br><br>Der Instanzknoten wendet seine eigenen Werte für die Eingabeparameter von Graf A im Kontext von Graf B an. In diesem Sinne kann Graf B mehrere Instanzknoten hosten, die alle auf Graf A verweisen, aber jeweils andere Werte oder Texturen als Eingaben in Graf A übergeben.<br><br>Alle Designers in der elementare Knoten-Bibliothek, die nicht [Instanzknoten](#atomic-node) sind, sind . |
| {: #invalidation}**Invalidierung** | Der Prozess, der erklärt, dass das Ergebnis eines Knotens veraltet ist.<br><br>Wenn ein Parameter angepasst wird, werden der Knoten, der diesen Parameter hostet, und alle Knoten, die stromabwärts liegen, ungültig. Daher müssen [ausgewertet](#evaluation) und [gerendert](#rendering) werden. |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #material}**Material** | Die Auflistung der Eigenschaften und Verhaltensweisen von Materie im Raum, die Oberflächen und Volumes umfasst.<br>Das Erscheinungsbild einer Entität im 3D-Raum wird durch ihr Material definiert.<br><br> Material können auf verschiedene Weise definiert werden, und alle Definitionen unterstützen nicht alle Eigenschaften wie Brechung, Anisotropie oder Glanz. Ein [Shader](#shader) ist eine bestimmte Implementierung einer Material-Definition.<br><br><b>Wichtig:</b> Der Begriff &quot;Material&quot; ist ein *Überschirmbegriff*, der verwendet wird, um auf verschiedene Dinge zu verweisen, einschließlich:<ul data-preserve-html="true"> <li data-preserve-html="true">Der [Shader](#shader), der zum Berechnen des Erscheinungsbilds einer Oberfläche oder eines Volumes verwendet wird;</li> <li data-preserve-html="true">Der Satz von [Texturen](#texture), der einem Shader bereitgestellt wurde;</li> <li data-preserve-html="true">Eine Material-ID, bei der es sich um ein Attribut einer 3D-Grundform handelt, die verwendet wird, um die Teile zu unterscheiden, die verschiedene Materialien verwenden.</li> </ul> |
| {: #mesh}**Mesh** | Ein 3D-Objekt, das aus [Scheitelpunkten](#vertex) besteht, die durch Kanten zu Polygonen verbunden sind, wie z. B. Dreiecken, die wiederum zu Flächen zusammengefügt werden. Diese Flächen können offen oder geschlossen sein.<br><br>Das Erscheinungsbild dieser Flächen wird durch das ihnen zugewiesene [Material](#material) definiert.<br>Die Detailstufe eines Meshs ist ebenfalls stark von dessen [Polycount](#polycount) abhängig. |
| {: #metadata}**Metadaten** | Daten, die Informationen über die Datei selbst, ihre Umgebung oder andere mit den Daten der Datei zusammenhängende Informationen bereitstellen.<br><br>Zu den allgemeinen Metadaten gehören der Autor der Datei, das Erstellungs- und Änderungsdatum, das Copyright und das Cover-Art.<br><br>In Designer kann der Inhalt eines [Pakets](#package) auch Metadaten enthalten. Beispielsweise kann ein Substance-Graf, der ein Fabric-Material generiert, Metadaten für die physikalischen Eigenschaften des Fabric enthalten. |
| {: #mipmap}**Mipmap** | Eine kleinere Version einer [Textur](#texture), die häufig automatisch berechnet wird.<br><br>Eine Textur kann eine Pyramide kleinerer Versionen von sich selbst aufweisen, die zur Laufzeit austauschbar sind, sodass die am besten geeignete Größe für optimale Qualität und Leistung verwendet wird.<br><br>Eine Textur mit hochfrequenten Details, die kleiner dargestellt werden, erzeugt beispielsweise wahrscheinlich *Moiré*-Artefakte. Darüber hinaus umfasst eine größere Textur wahrscheinlich mehr [Textur Samples](#texture-sampling).<br><br>Der Begriff &quot;Mipmap&quot; stammt aus der MIP-Zuordnungstechnik, wobei MIP für das lateinische &quot;*multum in parvo*&quot; steht, was &quot;viele Dinge an einem kleinen Ort&quot; bedeutet. |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| {: #node}**Knoten** | Objekt in einem Graf, der Berechnungen ausführt und ein oder mehrere Ergebnisse ausgibt.<br><br>Das Ergebnis wird mithilfe von Eingabeparametern gesteuert. Diese Parameter können als Steuerelemente im Eigenschaften-Dock oder als Eingabeparameter auf dem Verbindung selbst aufgelistet werden.<br><br>Es gibt zwei Hauptkategorien von Knoten: [elementare Knoten](#atomic-node) und [Instanzknoten](#instance-node). |
| {: #noise}**Rauschen** | Ein nicht-figuratives Bild, das eine zufällige oder pseudo-zufällige Verteilung von Formen und Farben darstellt. Rauschen werden häufig verwendet, um Flächen oder Verformungen zu variieren.<br><br>Die Knotenbibliothek von Designer umfasst eine große Sammlung von Rauschen-Generatoren, z. B. [BnW Spots](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md), [Clouds](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md), [Perlin Rauschen](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md) oder [Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md). |
| {: #normal}**Normal** | Bei der 3D-Berechnung ist die Normale einer Oberfläche ein [normierter](#normalization)-Vektor, der senkrecht zu dieser Oberfläche verläuft und von dieser Oberfläche nach außen verläuft.<br><br>Dieser Vektor stellt die Ausrichtung einer Fläche im 3D-Raum dar und wird für [Schattierung](#shader) verwendet, die entsprechend der Perspektive der Lichter und der Kamera der Szene auftaucht.<br><br>Eine [Normalen-Map](#normal-map)-Textur kann auf eine Fläche angewendet werden, um ihre Normalen zu ändern und Details hinzuzufügen. |
| {: #normal-map}**Normalen-Map** | Eine [Textur](#texture), die auf eine Fläche angewendet wurde, um ihre Normalen zu ändern.<br><br>Es wird meistens verwendet, um Details zu fälschen, die in der Geometrie eines Modells ineffizient enthalten wären. Durch die Verwendung einer solchen Zuordnung ist es möglich, zusätzlich zu den Pro-[Scheitelpunkt](#vertex)-Normalen auch Pro-[Texel](#texel)-Normale zu verwenden, was zu mehr Oberflächeninformationen und somit zu mehr Oberflächendetails führt.<br><br>Die X-, Y- und Z-Koordinaten der normalen Vektoren sind in den roten, grünen bzw. blauen Kanälen der Karte codiert. Je nach Zielgrafik-API ([DirectX](#directx) oder [OpenGL](#opengl)) ist der grüne Kanal möglicherweise invertiert. |
| {: #normalization}**Normalisierung** | Der Prozess der Neuzuordnung eines Wertebereichs in den Bereich [0, 1], wobei der höchste Eingabewert auf 1,0 und der niedrigste Eingabewert auf 0,0 neu zugeordnet wird.<br><br>Bei Vektoren wird die Länge (oder &quot;Stärke&quot;) des Vektors durch die Normalisierung auf einen Wert von 1,0 angepasst. |

## O

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

Gitter mit einer niedrigen Polyzahl werden als &quot;low-poly&quot; bezeichnet, während höhere Polyzahlen als &quot;high-poly&quot; bezeichnet werden. |
| {: #primary-input}**Primäre Eingabe** | Der Eingangsconnector eines [Instanzknotens](#instance-node), von dem dieser Knoten seine [Basisparameter](#base-parameter)-Werte erbt.<br><br>Die primäre Eingabe ist mit einem kleinen Punkt in ihrem Connector und dem Suffix &quot;(Primary)&quot; in ihrer Bezeichnung gekennzeichnet.<br><br>Wenn Knoten mit mehr als einer Eingabe verwendet werden, wird empfohlen, *stark* zu beachten, welche ihrer Eingaben die primären sind und wie sich dies auf die [Vererbung](#inheritance) im gesamten Diagramm auswirkt. |
| {: #procedural}**Procedural** | Das Merkmal einer Daten oder eines Artefakts, das durch Befolgen eines Computeralgorithmus erstellt wird, anstatt manuell.<br><br>Designer verwendet einen prozeduralen Workflow, bei dem der Algorithmus als Knotendiagramm entworfen ist.<br> <br><br>Prozedurale Arbeitsabläufe ermöglichen schnellere Iterationen, da Variationen und Anpassungen schnell generiert werden können, indem der Algorithmus und seine Parameter geändert werden.<br><br>Wenn das Ergebnis vollständig vom Algorithmus erzeugt wird, wird dieses Ergebnis umgangssprachlich als &quot;100% prozedural&quot; bezeichnet. Die prozedurale Generierung wird manchmal auf &quot;proc-gen&quot; gekürzt.<br><br>Die meisten Generatoren in der Knotenbibliothek von Designer sind zu 100 % prozedural, da sie kein Eingabebild benötigen, um ein Ergebnis zu erzielen. |
| {: #publishing}**Veröffentlichen (SBSAR)** | In Designer bezieht sich die Veröffentlichung auf das Exportieren eines [Pakets](#package) als SBSAR-Archivdatei, die [kompilierte](#compilation) Versionen der Diagramme, ihre Ressourcen ([Bitmaps](#bitmap), Schriften usw.), ihre Vorgaben sowie ihre [Metadaten](#metadata) enthält.<br><br>Die resultierenden [Sbsar-Dateien](#sbsar-file) können dann über ein [Substance 3D-Plug-in](https://substance3d.adobe.com/plugins/) verteilt und in anderen Substance 3D-Anwendungen oder Anwendungen von Drittanbietern verwendet werden. |

| {: #tiling}**Kacheln** | Die horizontale, vertikale oder beide Wiederholungen eines Bildes ohne sichtbare Nähte oder visuelle Diskontinuität.<br><br>Designer bietet viele [Knoten](#node), die [Geräusche](#noise) oder [Muster](#pattern) erzeugen, die diese Kachel enthalten.
