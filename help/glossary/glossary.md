# Erfahren Sie mehr über die in Designer verwendeten Begriffe und Konzepte.

## #&#x200B;

|  |  |
| --- | --- |
| <b><span id="three-d-scene" data-preserve-html="true"></span>3D-Szene</b> | Eine Sammlung von Objekten und Daten, die bei der Darstellung und Animation einer Visualisierung des 3D-Raums eine Rolle spielen:<ul data-preserve-html="true"> <li data-preserve-html="true">[Gitter](#mesh)</li> <li data-preserve-html="true">[Materialien](#material)</li> <li data-preserve-html="true">Kameras</li> <li data-preserve-html="true">Lichter</li> <li data-preserve-html="true">Animation</li> <li data-preserve-html="true">Simulationen</li> <li data-preserve-html="true">...</li> </ul>[Beliebte Dateiformate](https://www.adobe.com/de/products/substance3d/discover/3d-files-formats.html) zum Speichern von 3D-Szenen sind die [USD](#usd) von Pixar und die FBX von Autodesk. Alle Dateiformate unterstützen nicht alle diese Komponenten |

## A

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="alpha" data-preserve-html="true"></span>Alpha-Kanal</b> | Der vierte Kanal eines Farbbildes, der häufig zur Beschreibung der Deckkraft verwendet wird. |
| <b><span id="ambient-occlusion" data-preserve-html="true"></span>Umgebungs-Verdeckung</b> | Die Dämpfung von Umgebungslicht auf Oberflächen, die weniger belichtet und daher schwieriger zu erreichen sind. |
| <b><span id="anisotropy" data-preserve-html="true"></span>Anisotropie</b> | Die Eigenschaft, richtungsabhängig zu sein. Mit anderen Worten, ein anderes Ergebnis liefern, wenn auf einer anderen Achse gemessen oder beobachtet.<br><br>Anisotrope Materialien haben je nach Herkunft ein anderes Aussehen, und anisotrope Filter werden nicht einheitlich in alle Richtungen angewendet. |
| <b><span id="aov" data-preserve-html="true"></span>AOV</b> | &quot;Arbitrary Output Variable&quot; (AOV) ist ein Begriff, der in [Rendering](#rendering) verwendet wird, um zusätzliche Datenkanäle zu beschreiben, die von einem Rendering ausgegeben werden können, z. B. Tiefe, Normale oder benutzerdefinierte Daten. |
| <b><span id="api" data-preserve-html="true"></span>API</b> | Eine API (Application Programming Interface) ist eine Sammlung von Funktionen und Prozeduren, mit denen Benutzer auf die Funktionen und Prozeduren einer anderen Anwendung des Programms zugreifen können.<br><br>Eine API stellt eine kontrollierte und sichere Ebene zwischen dem Benutzer und einem Programm bereit. Es kann auch eine andere Programmiersprache verwenden, um die Interaktion mit diesem Programm zu vereinfachen und die Zugänglichkeit zu erweitern.<br><br>Designer bietet eine [Python-API](../scripting/scripting.md), die einfachen Zugriff auf eine Vielzahl von Funktionen bietet, mit denen Daten bearbeitet, benutzerdefinierte Tools erstellt und Workflows beschleunigt werden können. |
| <b><span id="atomic-node" data-preserve-html="true"></span>Atomknoten</b> | Die grundlegenden Bausteine von Diagrammen. Alle [Instanzknoten](#instance-node) können in Diagramme atomarer Knoten unterteilt werden.<br>Jeder Diagrammtyp verfügt über einen eigenen Satz atomarer Knoten. |

## B

|                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="baking" data-preserve-html="true"></span>Backen</b> | Der Vorgang zum Berechnen von Informationen aus einem 3D-Modell und Speichern der Ergebnisse in einer [Textur](#texture). Die Daten werden in der Textur entsprechend den [UVs](#uv) des Modells platziert. |
| <b><span id="base-color" data-preserve-html="true"></span>Grundfarbe</b> (Albedo) | Ein Kanal eines [Materials](#material), der mithilfe des PBR-Modells &quot;Metallische Raueit [Schattierung](#shader)&quot; definiert wurde.<br>Die Grundfarbe gibt die Farbe einer Oberfläche ohne Beleuchtungsinformationen an.<br><br>Es sollte nicht mit [Diffuse](#diffuse) verwechselt werden. |
| <b><span id="base-parameter" data-preserve-html="true"></span>Basisparameter</b> | Ein Parameter, der allen Knoten in einem Substance-Diagramm gemeinsam ist, die eine [Bitmap](#bitmap) berechnen.<br><br>Dazu gehören Kernaspekte der Bitmap, wie z. B. die Auflösung ([Ausgabegröße](#output-size)) und die [Bittiefe](#bit-depth) ([Ausgabeformat](#output-format)), oder wie die Bitmap berechnet wird, z. B. der [Tiling](#tiling)-Modus.<br><br>Basisparameter werden häufig [von anderen Knoten geerbt](#inheritance) oder von dem Diagramm geerbt, das den Knoten hostet. |
| <b><span id="bilinear-filtering" data-preserve-html="true"></span>Bilineare Filterung</b> | Ein Interpolationsvorgang, der im Computerbild verwendet wird, wenn ein [Texturmuster](#texture-sampling) nicht genau in der Mitte eines Pixels ausgeführt wird.<br><br>Dies kann beispielsweise auftreten, wenn ein Bild vergrößert wird. |
| <b><span id="bit-depth" data-preserve-html="true"></span>Bittiefe</b> | Die Anzahl der Bits, die zum Speichern des Werts eines Pixels in einer Textur verwendet werden. Bei höheren Bittiefen können mehr Werte codiert werden, was zu glatteren Farbverläufen führt.<br><br>Je nach Werttyp stehen verschiedene Bittiefen zur Verfügung: - Ganzzahlige Werte können mit 8 Bit (0 bis 255) oder 16 Bit (0 bis 65.535) codiert werden. - Gleitkommawerte können mit 16 Bit (+32767,9999 bis -32768,0) oder mit 32 Bit (-3,4E+38 bis +3,4E+38) codiert werden<br><br>Bilder mit niedrigem Dynamikbereich verwenden Ganzzahlwerte, um die Schritte von 0 bis 1 zu codieren. High Dynamic Rangen verwenden Gleitkommawerte, um numerische Rohwerte zu codieren.<br><br>In Substance-Graphen wird die Bittiefe durch den Parameter [Ausgabeformat](#output-format) gesteuert. |
| <b><span id="bitmap" data-preserve-html="true"></span>Bitmap</b> | Ein digitales Bild. Zwei Arten von Bildern kommen am häufigsten vor:<ul data-preserve-html="true"> <li data-preserve-html="true">Graustufenbilder haben nur einen Kanal: Luminanz (L);</li> <li data-preserve-html="true">Farbbilder haben drei Kanäle: Rot, Grün und Blau (RGB). Ein vierter kann vorhanden sein: [alpha](#alpha) (A), das häufig für die Deckkraft verwendet wird. Farbbilder in Designer sind immer RGBA.</li> </ul>  Bitmaps können als Raster mit Werten aufgefasst werden. Jede Zelle dieses Rasters ist ein Pixel, das für &quot;Bildelement&quot; kurz ist. Ein Pixel speichert einen Wert pro Kanal. Der Typ dieses Werts hängt von der [Bittiefe](#bit-depth) der Bitmap ab. |

## C

|                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="cache" data-preserve-html="true"></span>Cache</b> (Arbeitsspeicher) | Eine Datenerfassung - z. [Basisparameter](#base-parameter) und Ausgabebilder des Knotens - im Speicher gespeichert, um wiederverwendet zu werden.<br><br>Der Cache beschleunigt die Diagrammberechnung erheblich, indem das [Substance Engine](#substance-engine) nur die Teile eines Diagramms neu berechnen kann, die sich geändert haben. Beim Anpassen von Knotenverbindungen und -parametern sind alle Knoten, die dem Knoten vorausgehen, von diesen Änderungen nicht betroffen. Daher müssen sie nicht erneut [ausgewertet](#evaluation) werden, um das Diagramm zu aktualisieren. Stattdessen wird ihr Cache verwendet.<br><br>Der Cache kann bei der Arbeit mit hohen Auflösungen und Bittiefen in großen Graphen einen erheblichen Speicherplatz belegen. |
| <b><span id="channel-packing" data-preserve-html="true"></span>Kanal-Packing</b> | Eine Optimierungstechnik, bei der separate Bilder in die RGB(A)-Kanäle eines einzelnen Farbbildes gepackt werden.<br><br>Eine RMA-Textur ist beispielsweise eine [Raueit](#roughness)-Map (R), eine Metalitätsmap (M) und eine [Umgebungs-Verdeckung](#ambient-occlusion)-Map (A), die alle in einer einzigen Farbtextur zusammengefasst sind.<br><br>Eine weitere gängige Methode ist das Packing einer Graustufenstruktur in den Blaukanal einer [Normalmap](#normal-map), da der Blaukanal - d. h. die &quot;Nach oben&quot;-Komponente des Normalvektors - zur Laufzeit neu berechnet werden kann.<br><br>Der Knoten [RGBA merge](../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/rgba-merge/rgba-merge.md) ist nützlich für die Implementierung dieser Technik. |
| <b><span id="color-space" data-preserve-html="true"></span>Farbraum</b> | Eine Definition der Darstellung eines Farbbereichs.<br>Das digitale Codieren und Decodieren einer bestimmten Farbe erfordert eine solche Definition, um die verwendeten Zahlen zu verstehen.<br><br>Eine Bilddatei speichert Farbwerte mit einem angegebenen Farbraum, sodass diese Farben auf einem Bildschirm, der diesen Farbraum unterstützt, originalgetreu wiedergegeben werden können. Ein Display verfügt über spezielle Farbwiedergabefunktionen, die es ihm ermöglichen, einen bestimmten Farbraum ganz oder teilweise zu unterstützen.<br><br>Rohdaten - z. B. eine [normale Map](#normal-map) - wird immer in einem linearen Farbraum codiert und decodiert, da diese Farben nicht visualisiert werden sollen und keine Transformationen auf diese Daten angewendet werden sollen.<br><br>sRGB ist ein weithin unterstützter Farbraum. Weitere beliebte Farbräume sind Adobe RGB, Rec. 2100 und ProPhoto RGB. |
| <b><span id="cooking" data-preserve-html="true"></span>Kochen</b> (<span id="compilation" data-preserve-html="true"></span>Kompilierung) | Der Prozess der Übersetzung von Daten in eine andere Sprache, damit sie schnell und effizient ausgeführt werden können.<br>Das Ergebnis eines Substance-Diagramms muss zuerst kompiliert werden. Die Kompilierung ist Teil des [Evaluierungs](#evaluation)-Diagrammprozesses.<br><br>Diese Kompilierung wird für ein abgeflachtes Diagramm durchgeführt, was bedeutet, dass alle [Instanzknoten](#instance-node) durch ihre Quelldiagramme &quot;ersetzt&quot; werden, sodass ein größeres Diagramm verbleibt und dieses Diagramm kompiliert wird.<br><br>Ein kompiliertes Diagramm kann nicht bearbeitet werden. Verfügbare Parameter bleiben verfügbar, wenn sie [dynamisch](#dynamic-parameter) sind, während [statische](#static-parameter) Parameter gesperrt und ausgeblendet sind. |
| <b><span id="culling"></span>Ausrechnen</b> | Eine Optimierungstechnik zum [Rendern](#rendering) [3D-Szenen](#three-d-scene), die Geometrie aus den Berechnungen eines Renderings entfernt, wenn sie nicht sichtbar ist.<br><br>Dies kann Objekte oder Polygone umfassen, die sich außerhalb des Kegelstumpfs der Kamera befinden (*Kegelstumpfählung*), die der Kamera entgegengesetzt gerichtet sind (*Kegelstumpfählung*) oder vollständig durch andere undurchsichtige Objekte verborgen sind (*Kegelstumpfählung*). |

## D

|                                                                                        |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="dependency" data-preserve-html="true"></span>Abhängigkeit</b> | Eine Datei A, die von einer anderen Datei B so verwendet wird, dass Datei B nicht wie vorgesehen funktioniert, wenn Datei A fehlt.<br><br>Eine Abhängigkeit eines [Pakets](#package) kann ein anderes Paket sein, da darin auf ein Diagramm, eine Bilddatei, eine Schriftart usw. verwiesen wird.<br><br>Ein Paket speichert den Pfad zu seiner Abhängigkeit. Wenn die Abhängigkeit an diesem Pfad nicht gefunden werden kann, wird eine Warnung ausgegeben. Fehlende Abhängigkeiten können auch zu [Geisterinstanzknoten](#ghost-instance-node) in einem Diagramm führen. |
| <b><span id="diffuse" data-preserve-html="true"></span>Diffus</b> | Ein Kanal eines [Materials](#material), der mithilfe des PBR-Modells &quot;Specular Glossiness [Schattierung](#shader)&quot; definiert wurde. Diffuse gibt die Farbe einer Oberfläche an, wenn sie beleuchtet wird.<br><br>Es sollte nicht mit [Grundfarbe (Albedo)](#base-color) verwechselt werden. |
| <b><span id="directx" data-preserve-html="true"></span>DirectX</b> | Eine Sammlung von APIs zur Verarbeitung von Multimedia-Inhalten. Die 3D-API Direct3D ist in der Videospielentwicklung und anderen 3D-Branchen weit verbreitet.<br><br>Direct3D platziert den Ursprung einer Textur - d. h. die Koordinate (0, 0) - an der *oberen linken Ecke* (Y-nach unten), während die [OpenGL](#opengl)-API diese an der *unteren linken Seite* (Y-nach oben) platziert.<br><br>Dies bedeutet, dass eine DirectX [Normalmap](#normal-map) einen *invertierten grünen Kanal hat* im Vergleich zu GL. Tatsächlich beherbergt der grüne Kanal die Y-Koordinaten der normalen Vektoren. |
| <b><span id="displacement" data-preserve-html="true"></span>Versatz</b> | Der Vorgang des Verschiebens der [Scheitelpunkte](#vertex) eines 3D-Modells, häufig entlang der [Normalen](#normal).<br><br>Versatz wird häufig in Verbindung mit [tesselation](#tessellation) und [Normalmaps](#normal-map) verwendet, um detailliertere Informationen auf einer Oberfläche zu modellieren. |
| <b><span id="dynamic-parameter" data-preserve-html="true"></span>Dynamischer Parameter</b> | Ein Parameter, dessen Wert sich ändern kann. Mit anderen Worten, jeder Parameter, dessen Wert nicht konstant ist, ist dynamisch.<br><br><br>Dies umfasst exponierte Parameter, alle Parameter, die von einem exponierten Parameter betroffen sind, sowie alle Parameterwerte, die von [der Probenahme in einer Textur betroffen sind](#texture-sampling).<br><br>Im Gegensatz zu [statischen Parametern](#static-parameter) kann der Wert dynamischer Parameter im laufenden Betrieb angepasst werden, nachdem das Diagramm in eine [SBSAR-Datei](#sbsar-file) kompiliert wurde. |

## E

|                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="evaluation" data-preserve-html="true"></span>Auswertung</b> | Der Prozess der Auflösung der Weitergabe von Daten und Parametern im Diagramm. Die Auswertung überprüft die Gültigkeit eines Diagramms und seiner Verbindungen, wendet [Vererbung](#inheritance) an und [kocht](#cooking) das Diagramm.<br><br>In der Diagrammansicht wird eine Verbindung mit einer gepunkteten Linie dargestellt, wenn sie nicht ausgewertet wird.<br>Die Auswertung wandelt die Verbindung in durchgehende Linien um.<br><br><br>Jedes Mal, wenn ein Parameter in einem Diagramm angepasst wird, sind der Knoten, der diesen Parameter und alle Knoten stromabwärts hostet, [ungültig](#invalidation) und müssen erneut ausgewertet werden, bevor [gerendert](#rendering) wird. |

|                                                                         |                                                                                                                                  |
|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="filter" data-preserve-html="true"></span>Filter</b> (Knoten) | Ein [Knoten](#node), der eine Änderung auf ein Bild anwendet (z. B. eine Deformation) oder Informationen daraus extrahiert (z. B. eine Maske). |

## G

|                                                                                            |                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="ghost-instance-node" data-preserve-html="true"></span>Ghost-Instanzknoten</b> | Ein [Instanzknoten](#instance-node), der auf einen [Untergraph](#subgraph) verweist, der nicht gefunden werden kann, d. h. eine fehlende [Abhängigkeit](#dependency), wird als Geisterinstanzknoten geladen.<br><br>Ghost-Instanzknoten werden in den erwarteten Zustand zurückgesetzt, indem die fehlende Abhängigkeit aufgelöst und das [Paket](#package) erneut geladen wird. |
| <b><span id="glossiness" data-preserve-html="true"></span>Glossarität</b> | Ein Kanal eines [Materials](#material), der mithilfe des PBR-Modells &quot;Specular Glossiness [Schattierung](#shader)&quot; definiert wurde. Der Glanzgrad gibt die Unschärfe einer Fläche an, d. h. mikroskopische Variationen des Heights, auch als *Mikrofacetten* bezeichnet.<br><br>Ein hoher Glanz führt zu einem glatten Look, während ein niedriger Glanz zu einem rauen, matten Look führt.<br><br>Es ist das Gegenteil von [Raueit](#roughness). |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="histogram" data-preserve-html="true"></span>Histogramm (Bild)</b> | Im Kontext eines Bildes stellt ein Histogramm die Population der Werte in einem bestimmten Bereich dar - häufig [0, 1].<br><br>Diese Population wird mithilfe von vertikalen Balken visualisiert, wobei ein im Bild stärker vorhandener Wert zu einem höheren Balken für diesen Wert führt.<br>Die Balken werden horizontal von niedrigen (dunklen) zu hohen (hellen) Werten verteilt.<br><br>Histogramme von Farbbildern überlappen in der Regel die Histogramme der einzelnen Kanäle - in der Regel R, G, B. |

## I

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="inheritance" data-preserve-html="true"></span>Vererbung</b> | Im Kontext von Substance-Graphen beschreibt Vererbung die Eigenschaft von Nodes, die Parameterwerte von ihren Upstream-Nodes oder ihrem übergeordneten Graphen erfassen.<br><br>Geerbte Parameter beinhalten [Auflösung](#resolution) ([Ausgabegröße](#output-size)), [Bittiefe](#bit-depth) ([Ausgabeformat](#output-format)) und [Unterteilung](#tiling)-Modus.<br><br>Erfahren Sie mehr über die Vererbung in dieser [dedizierten Seite](../compositing-graphs/inheritance-compositing/inheritance-in-substance-compositing-graphs.md). |
| <b><span id="instance-node" data-preserve-html="true"></span>Instanzknoten</b> | Ein Instanzknoten stellt ein Diagramm A in ein anderes Diagramm B dar. In diesem Fall kann Diagramm A als [Untergraph](#subgraph) von Diagramm B bezeichnet werden. Jede Änderung in Diagramm A wird an alle Instanzknoten weitergegeben, die es darstellen.<br><br>Der Instanzknoten wendet seine eigenen Werte für die Eingabeparameter von Diagramm A im Kontext von Diagramm B an. In diesem Sinne kann Diagramm B mehrere Instanzknoten hosten, die alle auf Diagramm A verweisen, aber jeweils andere Werte oder Texturen als Eingaben in Diagramm A übergeben.<br><br>Alle Knoten in der Designer-Bibliothek, die keine [Atomknoten](#atomic-node) sind, sind Instanzknoten. |
| <b><span id="invalidation" data-preserve-html="true"></span>Invalidierung</b> | Der Prozess, der erklärt, dass das Ergebnis eines Knotens veraltet ist.<br><br>Wenn ein Parameter angepasst wird, werden der Knoten, der diesen Parameter hostet, und alle Knoten, die stromabwärts liegen, ungültig. Daher müssen [ausgewertet](#evaluation) und [gerendert](#rendering) werden. |

## M

|                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="material" data-preserve-html="true"></span>Material</b> | Die Auflistung der Eigenschaften und Verhaltensweisen von Materie im Raum, die Oberflächen und Volumes umfasst.<br>Das Erscheinungsbild einer Entität im 3D-Raum wird durch ihr Material definiert.<br><br>Materialien können auf verschiedene Weise definiert werden, und alle Definitionen unterstützen nicht alle Eigenschaften wie Brechung, Anisotropie oder Glanz. Ein [Shader](#shader) ist eine bestimmte Implementierung einer Materialdefinition.<br><br><b>Wichtig:</b> Der Begriff &quot;Material&quot; ist ein *Dachbegriff*, der verwendet wird, um auf verschiedene Dinge zu verweisen, einschließlich:<ul data-preserve-html="true"> <li data-preserve-html="true">Der [Shader](#shader), der zum Berechnen des Erscheinungsbilds einer Oberfläche oder eines Volumes verwendet wird;</li> <li data-preserve-html="true">Der Satz von [Texturen](#texture), der einem Shader bereitgestellt wird;</li> <li data-preserve-html="true">Eine Material-ID, bei der es sich um ein Attribut einer 3D-Grundform handelt, die verwendet wird, um die Teile zu unterscheiden, die verschiedene Materialien verwenden.</li> </ul> |
| <b><span id="mesh" data-preserve-html="true"></span>Mesh</b> | Ein 3D-Objekt, das aus [Scheitelpunkten](#vertex) besteht, die durch Kanten zu Polygonen - wie Dreiecken - verbunden sind, die wiederum zu Flächen zusammengefügt werden. Diese Flächen können offen oder geschlossen sein.<br><br>Das Erscheinungsbild dieser Flächen wird durch das ihnen zugewiesene [Material](#material) definiert.<br>Die Detailstufe eines Gitters ist ebenfalls stark von dessen [Polycount](#polycount) abhängig. |
| <b><span id="metadata" data-preserve-html="true"></span>Metadaten</b> | Daten, die Informationen über die Datei selbst, ihre Umgebung oder andere mit den Daten der Datei zusammenhängende Informationen bereitstellen.<br><br>Zu den allgemeinen Metadaten gehören der Autor der Datei, das Erstellungs- und Änderungsdatum, das Copyright und das Cover-Art.<br><br>In Designer kann der Inhalt eines [Pakets](#package) auch Metadaten enthalten. Beispielsweise kann ein Substance-Diagramm, das ein Stoffmaterial erzeugt, Metadaten für die physikalischen Eigenschaften des Stoffes enthalten. |
| <b><span id="mipmap" data-preserve-html="true"></span>MIPMAP</b> | Eine kleinere Version einer [Textur](#texture), häufig automatisch berechnet.<br><br>Eine Textur kann eine Pyramide kleinerer Versionen von sich selbst aufweisen, die zur Laufzeit austauschbar sind, sodass die am besten geeignete Größe für optimale Qualität und Leistung verwendet wird.<br><br>Eine Textur mit hochfrequenten Details, die in einer kleineren Größe angezeigt werden, erzeugt wahrscheinlich *Moiré*-Artefakte. Darüber hinaus enthält eine größere Textur wahrscheinlich mehr [Texturbeispiele](#texture-sampling).<br><br>Der Begriff &#39;mipmap&#39; stammt aus der MIP-Zuordnungstechnik, wobei MIP für das lateinische &#39;*multum in parvo*&#39; steht, was &#39;viele Dinge an einem kleinen Ort&#39; bedeutet. |

## H

|                                                                                |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b><span id="node" data-preserve-html="true"></span>Knoten</b> | Objekt in einem Diagramm, das Berechnungen ausführt und ein oder mehrere Ergebnisse ausgibt.<br><br>Das Ergebnis wird mithilfe von Eingabeparametern gesteuert. Diese Parameter können als Steuerelemente im Eigenschaften-Dock oder als Eingangsanschlüsse auf dem Knoten selbst aufgeführt werden.<br><br>Es gibt zwei Hauptkategorien von Knoten: [Atomknoten](#atomic-node) und [Instanzknoten](#instance-node). |
| <b><span id="noise" data-preserve-html="true"></span>Rauschen</b> | Ein nicht-figuratives Bild, das eine zufällige oder pseudo-zufällige Verteilung von Formen und Farben darstellt. Rauschen werden häufig verwendet, um Flächen oder Verformungen zu variieren.<br><br>Die Knotenbibliothek von Designer umfasst eine große Sammlung von Rauschgeneratoren, z. B. [BnW Spots](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/bnw-spots-2/bnw-spots-2.md), [Clouds](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/clouds-2/clouds-2.md), [Perlin noise](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/perlin-noise/perlin-noise.md) oder [Voronoi](../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/voronoi/voronoi.md). |
| <b><span id="normal" data-preserve-html="true"></span>Normal</b> | Bei der 3D-Berechnung ist die Normale einer Oberfläche ein [normierter](#normalization)-Vektor, der senkrecht zu dieser Oberfläche verläuft und von dieser Oberfläche nach außen verläuft.<br><br>Dieser Vektor stellt die Ausrichtung einer Fläche im 3D-Raum dar und wird für [Schattierung](#shader) verwendet, die entsprechend den Lichtern und der Kameraperspektive der Szene angezeigt wird.<br><br>Eine [Normalmap](#normal-map)-Textur kann auf eine Fläche angewendet werden, um ihre Normalen zu ändern und Details hinzuzufügen. |
| <b><span id="normal-map" data-preserve-html="true"></span>Normale Zuordnung</b> | Eine [Textur](#texture), die auf eine Oberfläche angewendet wurde, um ihre Normalen zu ändern.<br><br>Es wird meistens verwendet, um Details zu fälschen, die in der Geometrie eines Modells ineffizient enthalten wären. Durch die Verwendung einer solchen Map können pro-[texel](#texel)-Normale zusätzlich zu pro-[vertex](#vertex)-Normalen verwendet werden, was zu mehr Oberflächeninformationen und somit zu mehr Oberflächendetails führt.<br><br>Die X-, Y- und Z-Koordinaten der normalen Vektoren sind in den roten, grünen bzw. blauen Kanälen der Karte codiert. | <b><span id="normalization" data-preserve-html="true"></span>Normalisierung</b> | Der Prozess der Neuzuordnung eines Wertebereichs in den Bereich [0, 1], wobei der höchste Eingabewert auf 1,0 und der niedrigste Eingabewert auf 0,0 neu zugeordnet wird.<br><br>Bei Vektoren wird die Länge (oder &quot;Stärke&quot;) des Vektors durch die Normalisierung auf einen Wert von 1,0 angepasst. |
