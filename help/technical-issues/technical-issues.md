## Sicherheitslücke melden

Designer bietet verschiedene Möglichkeiten, Absturz und Fehler direkt zu melden.

>[!TIP]
>
> Bitte seien Sie beschreibend!
> 
> *Jeder* Absturz und Fehlerbericht, den Sie uns senden *, wird von einem Mitglied des Designer-Teams* überprüft.
> 
> Wenn Sie ein Problem melden, <b>geben Sie so viele Details und Kontext an, wie Sie </b> können. Dadurch können Sie das Problem wesentlich einfacher und schneller verstehen und eine Lösung finden.
> 
> Wenn Sie Feedback oder Vorschläge zur Verbesserung von Designer haben, teilen Sie uns dies bitte in [unserem dedizierten Forum](https://community.adobe.com/t5/substance-3d-designer/ct-p/ct-substance-3d-designer) mit. Die Community kann Vorschläge unterstützen und wir verfolgen diese Informationen.

### Absturzbericht

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

Bei Abstürzen der Anwendung wird in den meisten Fällen das Dialogfeld &quot;Absturz-Bericht&quot; angezeigt.

Sie können uns im Feld &quot;Beschreibung&quot; über die Umstände des Absturzes informieren, damit wir ihn untersuchen und hoffentlich in einer zukünftigen Version von Designer beheben können.

Geben Sie eine <b>gültige E-Mail-Adresse</b> frei, damit wir Sie kontaktieren können, wenn wir weitere Informationen benötigen, und/oder eine Problemumgehung für den Absturz bereitstellen können, den Sie erlebt haben.

</td>
<td style="border: 0;" valign="top">

![Dialogfeld für Absturz-Bericht](technical-issues.resources/crash-reporter-2.png "Dialogfeld für Absturz-Bericht"){zoomable="yes"}

*Zum Vergrößern klicken*

</td>
</tr>
</table>

>[!NOTE]
>
> Absturz-Berichte enthalten Designers Protokolldatei, Voreinstellungen und Projektdateien *, standardmäßig*. Daher werden in diesen Dateien möglicherweise einige <b>System- und Dateipfade</b> angezeigt.
> 
> Die Verwendung dieser Dateien ist <b>streng intern und </b> auf die Untersuchung des gemeldeten Problems beschränkt.

### Fehlerbericht

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

Sie können einen Fehler jederzeit in Designer melden. Wechseln Sie im Hauptmenü zu <b>Hilfe > Fehler melden...</b>, um das Dialogfeld &quot;Fehlerbericht&quot; zu öffnen.

Sie können uns über das Problem im Feld &quot;Beschreibung&quot; informieren, damit wir es untersuchen und Sie über unsere Ergebnisse informieren können.

</td>
<td style="border: 0;" valign="top">

![Dialogfeld &quot;Fehlerbericht&quot;](technical-issues.resources/bug-reporter.png "Dialogfeld &quot;Fehlerbericht&quot;"){zoomable="yes"}

*Zum Vergrößern klicken*

</td>
</tr>
</table>

Geben Sie eine <b>gültige E-Mail-Adresse</b> frei, damit wir Sie kontaktieren können, wenn wir weitere Informationen benötigen und/oder eine Problemumgehung für das Problem bereitstellen können.

Aktivieren Sie die Option <b>Zusätzliche Informationen senden</b>, um die Protokolldatei, Voreinstellungen und Projektdateien von Designer in Ihren Bericht aufzunehmen.

>[!NOTE]
>
> Einige <b>System- und Dateipfade werden möglicherweise in diesen zusätzlichen Dateien </b> angezeigt.
> 
> Die Verwendung dieser Dateien ist <b>streng intern und </b> auf die Untersuchung des gemeldeten Problems beschränkt.

Klicken Sie auf die Schaltfläche <b>Anlage</b>, um eine Datei an Ihren Bericht anzuhängen, damit wir das Problem genauer bewerten können. Sie können gerne Projektdateien, Screenshots, Bildschirmaufnahmen oder andere Dateien hinzufügen, die Ihrer Meinung nach für das Problem relevant sind.
