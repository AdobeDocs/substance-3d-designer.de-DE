# Probleme mit der Benutzeroberfläche

Auf dieser Seite werden technische Probleme im Zusammenhang mit der [Benutzeroberfläche](../../interface/interface.md) von Substance 3D Designer aufgelistet. Für jede dieser Probleme werden Schritte zur Fehlerbehebung angeboten.

## Die Skalierung der Benutzeroberfläche ist falsch

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

**![(出错)](user-interface-issues.resources/error.svg) Problem**

Die Elemente der Benutzeroberfläche sind zu klein oder zu groß.

</td>
<td style="border: 0;" valign="top">

**![(滴答)](user-interface-issues.resources/check.svg) Empfohlene Schritte**

Designer bezieht die spezifische Skalierung der Benutzeroberflächenelemente *vom Betriebssystem*. Daher sollten alle Anpassungen an der Skalierung der Benutzeroberfläche in den Anzeigeeinstellungen des Betriebssystems vorgenommen werden.

Um sicherzustellen, dass die Anzeigeeinstellungen in Designer korrekt angewendet werden, *melden Sie sich von* Ihrer Betriebssystembenutzersitzung ab und melden Sie sich nach Änderung dieser Einstellungen wieder an.

</td>
</tr>
</table>
