# Grafik der Substance-Modellfunktion fehlt

## Ende der Lebensdauer

Die Diagramme der Substance-Modelle waren unser erster Einstieg in die parametrische Modellierung und wurden später <b>eingestellt</b> in Version <b>13.0.0</b> von Substance 3D Designer.

Die Version <b>12.4.1</b> ist die *letzte* Version von Designer mit Unterstützung für Substance-Modellgrafiken. Benutzer dieser Funktion sollten daher nicht auf höhere Versionen aktualisieren.
